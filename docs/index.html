Dungeon Keeper 2, reimplemented.

Netherhold is a Dungeon Keeper 2 remake and reimplementation in C#/.NET with a Unity presentation layer. The goal is to reproduce the original game's observable behavior with a deterministic simulation independent of rendering.

Explore the source codeBuild & test instructions
Development status: Netherhold is a research and development project, not a finished or fully compatible replacement. Original Dungeon Keeper 2 game files are required for game content and are not included.

Project approach

Gameplay fidelity

Behavior is researched against the original game rather than guessed. Compatibility and campaign outcomes are still being verified.

Deterministic C# simulation

The .NET simulation is designed to operate independently of the Unity presentation layer, supporting repeatable tests and investigation.

Unity presentation

A classic-style visual presentation with menus, HUD and level rendering is under active development.
