A fastcall on the state object, no stack argument, called only from the job dispatcher's case for id 22 (0x0047895A). It calls SetState(176), which zeroes +0x44 on commit; on success it stores World_GetGameTurn() + 1 (0x00517490, the 250 ms turn counter) in +0x44 and returns 1, else returns 0. The dispatcher 0x00476FC0 then decrements the field once per call and returns early until it reaches zero, so a hero entering Wait at turn T runs nothing for T + 1 calls. The debug dump calls the field SuspendTime. No other function writes it. Our HeroJobRules.Wait has no hold (Q499).
