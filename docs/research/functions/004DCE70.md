It dispatches on the room type byte +0x18: any room but the three below gives its TotalCapacity at room+0x67 (CONFIRMED; furniture for the furniture rooms, the slab count for a Guard Room, Hatchery, Treasury and the rest of 0x004E3ED0's default arm), a Temple (13) gives 2 only while it holds object 66, the Temple Hand (CONFIRMED, and met by the owner's 2026-09-11 two-Dark-Angel run), and Prison (11) and Combat Pit (16) take the branch at 0x004DCEDD that counts the slabs of the chain from room+0x2D/+0x2E which 0x00454110 accepts. That predicate requires the interior marker byte slab+0x0C == 0xFF before its type switch (read 2026-09-30, record 00454110), so those two rooms contribute their interior cells only, never the rim; arm 9's unconditional true applies only after that guard. LIKELY overall: read statically. The Lair's flat 1.0 is not here but in the caller 0x004DBF90, which sums these contributions per matching room and subtracts 1.0 per creature held (portal-creature-action.md).
