Read whole by decompilation while following 0x004B3AD0. It advances values +4/+8 by signed short increments +0x14/+0x18 toward targets +0xC/+0x10, clamps on reaching a target, and clears the completed increment. Flag +0x4C bit 6 can arrange a return toward zero using word durations +0x1C/+0x1E. The meaning of these values was not established; this routine supplies no Tremor action duration.

For objects: +4/+8 are the RenderInfo scale pair the mesh draw divides by 4096 (object-drawing.md section 5).
