from 0x005558D0 on world +0x15A0 with range (2r+1)^2. The remainder and
quotient locate the sampled tile in that square. Table 0x006BC3B0 contains
N, NE, E, SE, S, SW, W, NW, center. Checks world slot +0x1FC bounds and
navigation bit 8 clear; writes the first passing tile, returns 1. None: 0.
The selected neighbor can lie one tile beyond the sampled square.
