Each channel starts with an unsigned eight-bit DC value before the shared
coefficient decoder 0x00665EF0 and transforms. This is not the engine texture's
predicted luma/chroma path. Opaque RGB output rounds the fixed-point samples by
adding 0x8000 before shifting. The optional mask consumes a presence bit and,
when present, 64 mask bits after the colour channels. F1 implements the unmasked
path; matched native pixel equivalence remains unestablished.
