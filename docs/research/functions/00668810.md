Each channel starts with an unsigned eight-bit DC value before the shared
coefficient decoder 0x00665EF0 and transforms. RGB output rounds the 16.16
samples by adding 0x8000 before shifting; alpha is shifted without rounding. The
optional mask consumes a presence bit and, when present, 64 mask bits after the
colour channels; masked pixels take the header's replacement colour. Our code
decodes the unmasked path. HYPOTHESIS: the x87 precision in force when the game
calls it, which nothing on this path sets; 64 and 53 bits give our pixels, 24 bits
changes 18 of the 29 images (Q812).
