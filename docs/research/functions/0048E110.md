A fastcall on the creature. If its type byte +0x36F is 0x1D (Lord of the Land), 0x15 (King Reginald) or 0x1C (Stone Knight) it returns 1; otherwise (+0x3EA >> 11) & 1. The health routine 0x004B2CE0 calls it for a creature attached to no room (+0x3B9 zero): true skips the collapse, so the creature goes to the death block. The bit is set by 0x0048E140 from a party member's or placed hero's Flags2 bit 2 (0x00520460) and by trigger action 1's Flag bit 2.
