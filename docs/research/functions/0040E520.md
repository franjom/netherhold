Callback of cursor state 11 (Slap.png, 15 frames at 30 a second) in the state table at 0x0068F638. Event 0 (a request, from 0x0040ABC0): when the current state is 11 and its frame is at most 3 nothing changes; otherwise it adopts the requested state and restarts the clock and frame. Event 3 (every update, before the completion test): when byte 0x006CE95C is zero and the frame is at least 3 it requests HAND/0xC5, positional (slot +0x20, handle 0, the HAND category from manager slot +0x58) at the pick record's world position (+0x1078/+0x107C) with height 0x2000, and sets the byte to 1. Event 2 (completion): clears the byte and returns 0, so the state reverts to the saved one. Other events return 1.

The byte is cleared only at completion, so a swing restarted after frame 3 plays no second sound, and one interrupted by another request leaves it set until a later swing completes. The state is requested by 0x00408EE0 (right press over a slappable creature, object or trap). Built as HandCursorFeedback.Advance; see sound-effects.md section 6.
