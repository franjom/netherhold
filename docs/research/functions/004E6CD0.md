A trivial getter, like its siblings 0x004E6C90 and 0x004E6D10: bounds-check the type (0 < id <= 26), load the +0x21 integer of the record at 0x006a1e9f + id x 41 (indexing site 0x004E6CEC), return it, and 0 when out of range. The shipped values are Treasury 5, Portal and Hero Portal 52, Hatchery 6, Dungeon Heart 5, Prison 3 and Temple 4, zero elsewhere. The getter and table are CONFIRMED. Caller 0x0049EF90 stores a nonzero result into the object's +0x13A process state and resets its age; gold keeps the Treasury/Heart and Temple routes.
