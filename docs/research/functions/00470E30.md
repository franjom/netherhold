In order: a target gone from the live-tag table ends it (resume 199); an ordinary creature target is unlinked and re-selected every tick, while a forced target skips selection; a changed choice stops and enters the current shared resume word (199, or 202/251 installed by selection); the fear counter can enter state 203 (without the low-health test); a chase of a fleeing target past variable 213 (Good, 3 s) or 214 (Evil, 7 s) gives it up; strict reach within `+0xF1` with line of sight ends it. Otherwise `+0xF5` counts down and at zero a fresh route is requested and reset to 10; movement is delegated to `0x00470C80`. It never calls `0x00471890`. It also reads variable 211 BackOffMinimumDurationSeconds (balance-variables-in-the-binary.md). Marked CONFIRMED (binary) in the doc's Confidence section; built in ADR-0169.

The Flanker's refresh point (decompiled 2026-10-04): when def +0x67E is 3 and the target kind is 0, h = the target creature's heading +0xF4, d = 0x2000 when the attack nibble (+0x529 & 0xF) is 0 else 0x400, and the point is (tx - (d*S[h])>>16, ty + (d*C[h])>>16) with 64-bit products. S (0x006C1488) and C (0x006C1C88, S + 512 entries) are 2048-entry 16.16 sine and cosine tables (S[1] = 201, C[0] = 0x10000; later entries inferred from the shape). With the heading convention forward = (sin h, -cos h) the point is d behind the target's facing. If 0x004B35C0 rejects it, the target's own position is used. Built: ApproachRules.Destination aims behind the heading through TrapRules.Sine/Cosine, standing target or not (ADR-0369).
