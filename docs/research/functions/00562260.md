Uses RegQueryValueExA with the caller's buffer and size. A returned type is
collected but not compared. This explains why a native progress array stored
under type 9 still loads, while managed Registry.GetValue cannot decode it.
The F1 Windows import performs its own read-only raw-byte query; it is a consumer
of this finding, not an implementation of the native registry wrapper's contract.
