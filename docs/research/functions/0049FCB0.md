Recall cadence and effect (decompile re-read 2026-11-11). While the Call to Arms object's due turn `+0x14A` is below the game turn it runs the recruitment (`CallToArms_Recruit`, tile of the object) and sets the next due turn to the game turn plus the ticks-per-second global 0x006F2590. The due turn must be strictly below the game turn (0x0049FCE0 compare, 0x0049FCE6 branch), so with 4 ticks per game second (Q132) a pass runs every 5 turns. Each pass increments the byte counter `+0x14E`; when it reaches 3 it raises view effect 0x14A (330) through world slot +0x38C at the object's point (+0x1A, heading +0xF4, owner +0x28) and resets the counter to 0. So effect 330 plays on every third pass. State 13 (0x0049FC50) zeroes `+0x14E` at 0x0049FC82 together with the state-14 store (0x0049FC8B) and sets the due turn to the game turn plus 0x006F2590 (0x0049FC95); a text search found no other writer of state 14. The call through slot +0x38C (0x0049FD63) passes the effect id 0x14A, the owner word `+0x28`, the address of the point `+0x1A` (x, y, z), the address of the heading `+0xF4` and an out-pointer. The order inside one pass is the recruitment (0x004BDDA0), the due-turn store, the counter increment and store, the compare with 3, the slot call and the counter reset. A set `+0x14F` (the slap-ended flag of 0x0049C6A0) moves the process to state 0xF with its age cleared at 0x0049FCB7 and falls through, so a due recruitment and effect still run in that pass.
