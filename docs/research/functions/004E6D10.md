A trivial getter: bounds-check the type (0 < id <= 26), load the +0x1d integer of the record at 0x006a1e9f + id x 41 (indexing site 0x004E6D2C), return it, 0 when out of range. It is non-zero only for Portal, Dungeon Heart, Prison, Torture Chamber, Temple, Combat Pit and Hero Portal, and always equal to that room's +0x19 value (197, 71, 114, 130, 101, 137). That both slots hold state ids is CONFIRMED (their accessors feed SetState at 0x0046EF7F, 0x0046F127 and 0x004E9035), but what separates +0x1d from +0x19 is UNKNOWN and the docs do not say which call site uses this one.
