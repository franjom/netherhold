The same resource and slot leave phase, rate and flags alone (the one more skip: same slot, flags bit 6 from the alternate-clip swap, new identity equal to the original kept at +0xCB). The compared slot is the arm's requested slot, not the resolved art. An install first writes the mark pair +0xC3/+0xC7 (the 2026-11-03 History line), then calls 0x004B37D0 with the resource, a scalar (4096, or the speed getter's result in the walk/run arms), the requested slot and an immediate flag.
