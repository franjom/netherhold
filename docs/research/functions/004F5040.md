Fastcall on the room. Walks the room's listed objects head first (newest first); for the n-th it walks the tile chain and takes the (n / 3)-th tile that passes neither slot test (`0x00454110`, `0x00454230`). It sets the crate at that tile's centre, `x * 0x1000 + 0x800` and `y * 0x1000 + 0x800`, height 0, through the position setter (`0x004B5560`); sets its heading `+0xF4` to `Math_Atan2` of the room's position word (`+0x27`, x and y times `0x1000` plus `0x800`) minus the crate's point, masked `0x7FF`; and writes the render offset words `+0x95/+0x97/+0x99` by `n % 3`: `0x249, 0, 0`, then `0xFDB7, 0, 0` (`-0x249`), then `0, 0, 0x300`. It then calls one further routine, unread. A crate with no tile left stays where it is; the routine returns 0 then, 1 at the end of the list. Ours: `CrateRules.Arrange` sets the tile, the tile centre and heading 0; the aim and the three render offsets are not built.
