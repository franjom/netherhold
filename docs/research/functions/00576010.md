Called only from 0x00575780, after the frame is presented. First loop: entries on list 0x007651EC lose their Tremor block +0x40 and flags 0x20/0x40/0x80. Then it walks the previous frame's LRU list (tail 0x00764BD8): 0x00571B00 moves each entry touched this frame to the current list (head 0x00760B6C), so what remains was not touched. For each such entry with a static light list (+0x34 non-null), every entry in x-3..x+3, y-3..y+3 stamped this frame (+4 == 0x00760B10) gets static count +0xC4 = 0; its table stamp +0x10 is kept. The entry is unlinked from its bucket, its mesh lists +0x2C/+0x34 freed, flags &= ~0x16, 0x00574750 called, +0x3C/+0x40 and the entry freed. Finally the current list becomes the previous one (0x00764BD8 = 0x00760B6C, head = 0).
