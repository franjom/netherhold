Frees and reallocates +0xEA2 (count*0x24 rotations), +0xEA6 (count*0xC positions), +0xEAA and +0xEAE (count*4 floats); count from the file's dword 0 into +0xEBE. Frames start at file offset 16 and are 14 floats (56 bytes): position copied as is; the 9 rotation floats stored as S*Mt*S with S = diag(-1,1,1); float 12 to +0xEAA (field of view), float 13 to +0xEAE (view distance). Returns 0 and frees everything on a failed load or allocation. The file goes through the resource cache 0x00556BA0 (DAT_006DA470). Layout checked against all 80 shipped files.
