Read whole 2026-10-26 by decompile: thiscall on the state object (creature +0x24E), one unsigned argument. If +0x58 < amount, +0x58 = 0; else +0x58 -= amount; returns +0x58. +0x58 is the tiredness latch the needs routine loads with the definition's TimeSleep (+0x5D6) (creature-needs-routine.md; ours NeedRules.IsTired).

Two callers. Sleeping_UpdateHook 0x0047AC00 (0x0047AC0B) calls it with 1 in state 83, so sleep drains the latch a turn at a time. Hand_SlapCreature 0x0048B8A0 (0x0048BA6A) calls it with def +0x5D6 >> 2, but only inside the arm at 0x0048BA13 that tests +0x25E == 0x53 after its SetState (0x0048BA06) returned nonzero. Every nonzero return of Creature_SetState 0x00476D30 commits +0x10 = the target at 0x00476F84, after the enter hook, and the slap's targets are 77, 67 and 120, so that arm never matches: a slap never reduces the latch (slap-states.md section 1). The slap caller is dead in practice; the sleeping caller is not mirrored in ours (state-category-hooks.md section 3).
