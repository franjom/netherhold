It is the only reader of variable 132, EPLossSecondWhileNotTraining (global 0x006F2904), and calls the adder 0x00457880 with the negated value unless the current category is 13; the category comes from 0x00478050, which looks through a category 2 utility state to the saved state at creature+0xDF (training.md section 8). It is called once per update from the creature update 0x00488930 at 0x00489584 (+0xC54, after its call to 0x0048E160), so it runs per tick, not per second as the variable's name says. The word at 0x006F2904 is loaded with MOVSX and negated with no division (its only writer is the Variables_SetMisc arm at 0x0051D1E3, which stores AX unchanged), so a non-zero value would drain four times the named rate (section 6.2). The category 13 skip is followed by the truncating wrapper 0x004858B0, which jumps to 0x004859CD and the adder 0x00457880; an oversized loss clamps the balance to zero there. The variable ships as 0, so the mechanism is live but switched off (balance-variables-in-the-binary.md). Ours only exposes the shipped zero as TrainingRules.ExperienceLostPerSecondWhileNotTraining; no drain is simulated, so READ.
