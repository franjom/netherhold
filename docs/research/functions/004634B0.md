The first of the five hatchery states (label "eating"). It calls `0x004DED00` for a hatchery of the owner, then the room helper `0x00471A70(room, 92, 0x80)` from its one call site `0x004634E3`, and returns the helper's result; a creature already on that room's tile goes straight to 92 (travel-states.md §8, CONFIRMED). The id was misfiled under `0x5A` before ADR-0072's frame fix, which is why Q174 once looked like a missing walk (eating.md §8). Built as `EatingRules.FindHatcheryState` (ADR-0176).
