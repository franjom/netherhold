Reached from 0x004C0FE0 (slap action 6) with an angle, it plays sound 0xC5 and increments player +0xEE6, then dispatches three ways on the byte at +0x12C (the object type id in ADR-0115's reading). The default arm builds a knockback from the sine/cosine tables at 0x006C1488 and 0x006C1C88; one arm gates on the tile under the thing being terrain 35 (Hero Lair) and walks a creature's level toward a target from thing +0x14A with 0x0048AFA0 / 0x0048B120, which is why Q328 found it among the level-decrement callers. Call to Arms removal (packet action 63, 0x005136E0) goes through it: the keeper's own flag is thrown and set to state 15, refused in states 12, 15, 19, 20 (STRONGLY INFERRED in call-to-arms.md). Only that flag arm is built (CallToArmsRules.Remove, ADR-0279); the knockback and the Hero Lair arm are not, and which object the Hero Lair arm reads +0x14A from is unsettled.
