Sides are numbered N, E, S, W (`0x00698A60`: (0,-1), (1,0), (0,1), (-1,0)). With dx, dy the point minus the tile: dx 0 gives S when dy > 0 else N, turning +1; dx < 0 and dy 0 gives W, +1; dx < 0, dy > 0 gives S +1 when -dx < dy, else W -1; dx < 0, dy < 0 gives N -1 when dx != dy and -dx <= -dy, else W +1; dx > 0 and dy 0 gives E +1; dx > 0, dy > 0 gives S -1 when dx < dy, else E +1; dx > 0, dy < 0 gives N +1 when -dx != dy and dx <= -dy, else E -1. The dig walk `0x00469AF0` passes the imp's tile, or the last seam after a mine. Ported as MiningSlots.StartSide (ADR-0289).
