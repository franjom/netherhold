Decompiled 2026-10-06: it returns 0 when the creature's level (+0x403) is at or above TrainingRoomMaxExperienceLevel (0x006F28FC); otherwise it returns whether 0x00496D00 reports an action running, so the state lasts while the action 0x2C (or another) plays.
