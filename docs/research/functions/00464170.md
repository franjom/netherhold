Called only from `0x00489076`, on a tick the tile coordinates changed, for a creature whose definition has `+0x686` bit 0, whose owner's player byte `+0x10FC` is at least 3 and whose effective category is not 22. Inside: nothing carried (`+0x3C3`, `+0x3C5`), effective category 3 (`0x00478050`), the imp's tile more than two tiles from `+0x8C/+0x90` on either axis, and dword 6 of the kind record at `0x006986A0` set for the current kind. Then `0x004687C0(14)` on the tile; on success the walk's resume is set to 10 (`0x00478080`). The dispatcher `0x00468520` has no case 14, so this is the only way a kind-14 task is taken (imp-claim-path.md §3, §5). Ours runs it on deposit walks only (ADR-0286).
