Arguments: creature, point pointer, options. Bits 1 and 2 of the options land in +0x3E6 bits 17 and 18 and bit 7 in bit 19, so both 0 and 1 clear them. The globals: 0x006EC9D0 the owner's compact id, D4/D8 those two bits, DC definition bit 5 (lava), E4 definition bit 4 (water), E0 bit 19. The route runs from the creature's position >> 4 to the point >> 4; the result is whether the route structure's found word is nonzero. The keeper's front and staging tests use it, so a reachability question in DK2 writes creature state.
