Reads the thing id from the word at action+0x0 and the player from the word at action+0x10. It refuses
unless the slot is live (byte table 0x006ED540), the thing's class dword +0x12 is 4 (a door) and its owner
word +0x28 equals the player. It then calls Door_SetLockMode (0x004A6800) with 0 when +0x111 is non-zero,
else 3, so the action is a toggle. The word at action+0x4 is never read. Returns 1. A packet slot mapped to
the wrong thing is a silent no-op here, not an error.
