A thiscall on an object with the event type and two unused arguments. Read 2026-10-04 (Q285). It follows the sibling chain from `+0x144` while the id is positive. For each record whose type byte `+0x0E` equals the argument and whose active bit is set, it walks `ChildTriggerId` through `0x004A3E90` with the record's own `+0x0F`. That walker resolves conditions through the world dispatcher `0x00518270`, answers type 18 false without evaluating it, runs actions through `0x00518AD0`, recurses, and returns 0, so the `0x00508640` call behind it is never reached. Its one caller is `Object_SetOwner` `0x0049C850`, with type 18, when an object leaves the neutral player. Who writes `+0x144` was not found. Not built: ours has no object trigger roots.
