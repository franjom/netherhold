Called by 0x00450470 for each room tile. Nothing off the map or for a roomless tile. Selector 1 and 10 write 0; 2, 5, 7 a mask (0x004EFCE0, 0x004EFF00, 0x004EFDE0: bit k = neighbour on the map with the same terrain id and owner); 3 and 4 a code from the orthogonal neighbours (0x004EF730, 0x004EF980); 6 nothing; 8 the Heart tables (0x004EFBE0, or 0x004EFC60 when room +0x9A bit 0, checked at 0x004EDD42); 9, 11, 12 position tables from the first slab (0x004EFFE0, 0x004F0070, 0x004F02D0); 13 the 3x1 gate code (0x004F00F0). Selector 7 then posts bridge command 6 (0x00517480) for a rectangle around the tile. The ruin's tile walk also calls it (hero-parties-and-effect-generators.md).
