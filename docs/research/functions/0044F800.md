address: 0x0044F800
name: Tile_RoomPlacementObstructed
role: True when something on a tile stops a room tile being placed there: any door or trap (whoever owns it), or a living non-Imp creature of another player. Objects never obstruct.
confidence: LIKELY
status: READ
evidence: docs/research/bridge-placement.md#1-the-placement-predicate-0x0044f630

Arguments: the player tag (word), the runtime tile, and a third argument never read (RET 0xC; no [ESP+0x1C] load). Walks the tile's thing chain (0x006EE540 indexed by the tile's head word, next at +0x0C) once: a thing of class (+0x12) 3 or 4 obstructs whoever owns it; a class 0 thing obstructs when its kind byte +0x36F is not 1 (the Imp), its owner +0x28 differs from the tag and its +0x3E6 bit 0x200000 (dying) is clear; classes 1, 2 and above 4 are skipped. Class 3 is the trap (0x004A7940 calls 0x004B28D0(3)) and class 4 the door (the door constructor 0x004A5070 links type 4); class 0 is a creature and class 2 an object (0x0040D8F0). So no object stops a room tile being placed, whatever its flags: the test reads no object definition, so an Obstacle object does not block either. Called by 0x0044F630 for every arm. Not built (Q501).
