Read whole. The parameters are (buffer, x, y, text, colour, flags, clear). The 0x50-byte style object follows them by value: 0x0040A3E0 copy-constructs it from 0x00741320 through 0x0062C2D0, and it reaches 0x0062CAE0 as &stack0x20. The colour pointer goes to 0x0062C3C0, the setter that 0x005534D0 calls with FF FF FF FF 00.

With clear set, the function zeroes the buffer. With flags 0, it lays the text out unbounded at (x, y) in a 0x7FFF box. Otherwise the flags pick the alignment:
- **Horizontal (0x0062CA70):** bit 0 or 8 gives 0, bit 2 gives 2, bit 1 gives 1.
- **Vertical (0x0062CA00):** bit 4 or 0x80 gives 4, 0x20 gives 5, 0x40 gives 2.

It then lays the text out in the buffer's box (+0x277, +0x27B) through 0x0062CAE0. The path subtitle passes flags 0x44 (horizontal 2, vertical 2). While scrolling it passes 0x14 (horizontal 2, vertical 4).

What each mode means on screen is unread, hence LIKELY. Reading 2 as centre is INFERRED.
