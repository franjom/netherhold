- `0x00465897` calls `0x00496D00` on the creature; nonzero (an action still running) jumps to the common exit at `0x00465B68`: the state holds.
- `0x004658B0` calls `0x00508070(task word +0x8A, 2)` on the task list (`[[+0x8]+0x2A]+0x1105`). Zero (the task gone) clears `+0x8A` and calls `0x00476D30(10, 0)`: to state 10.
- `0x004658DC` calls the hands test `0x00464360(1)`. Nonzero calls the store chooser `0x00464400`; nonzero from that releases the task through `0x00508160(+0x8A, +0x94, +0x96, 0)` and returns 1 (the chooser has already set the walk to the store). A full imp with no store, or an imp not full, falls through to `0x0046591D` and goes on towards another strike.

So the point at which a miner breaks off is the ordinary hands test, full at `MaxGoldHeld(level)` less variable 74 (340 in every shipped level): a level 1 Imp (1,400) leaves after four strikes of 273 (1,092 against 1,060), not when the next strike would not fit. Level 1's capture agrees: imp 455 holds 1,092 from tick 216 on. Built as `ImpTaskSystem.MinersHandsFull` (ADR-0296).

**The seam's end** (`0x00465A6F`–`0x00465B68`, read 2026-10-01) has state 14's shape (`0x004655D0`): it reads the entry (`0x005081C0`) and removes it (`0x00508040`) only when the entry's tile is the task tile `+0x8C/+0x90` and its kind byte is **1**, which a seam's kind-2 entry never is, so the miner leaves its task to the next dig walk (`0x00469AF0`, `0x00469EBF`). Then state 10, and kind 14 when the tile passes `0x00453FC0` and `0x00453B30` and has none (`0x00508200`, `0x00507BB0(14)`). The raise therefore needs the kind-2 task alive at the miner's post-action check (ADR-0305).
