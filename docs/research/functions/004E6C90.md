A trivial getter: bounds-check the type (0 < id <= 26), load the +0x19 integer of the record at 0x006a1e9f + id x 41 (indexing site 0x004E6CAC), return it. The values are each room's working state (Treasury 188, Lair 79, Portal 197, Hatchery 92, Library 53, Training 108, Prison 114, Combat Pit 137, Crypt 274 and so on); that they are state ids is CONFIRMED because the accessors' results go straight to SetState (0x0046EF7F, 0x0046F127, 0x004E9035). The room drop 0x004E8DA0 also reads the slot directly. Built as the table in DropLandingRules.RoomDropState; several of the states it names are not built and idle (hand-drop-landing.md, differences).
