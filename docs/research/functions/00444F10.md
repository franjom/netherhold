For each side N, E, S, W: when the outside neighbour is a wall (+0x17B bit 0x10000 or 0x004434F0) and not the same room, it adds a piece from definition slots +0x13C, +0x157, +0x172, +0x18D or +0x1A8, chosen by whether the adjacent sides continue the wall and, in rooms with a phase (room +0x92/+0x96 >= 0), by x or y parity plus the phase (+0x18D vs +0x1A8). Room type 0x12 picks by offset from the room origin (+0x2D/+0x2E) and reads +0x121; 0x15 adds nothing; 0x17 picks by orientation +0x9B and reads +0x7F + index*0x1B. The dispatch is read; which slot is which piece is inferred, hence LIKELY.
