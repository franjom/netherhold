The bit tested is the runtime record's, which 0x00504D80 builds as file flag bit 0 OR (type byte != 0), and the loader compacts only slots with a nonzero type that load. So a slot is available when its type is nonzero, whatever its file flag bit 0: Vampire, Knight, Thief and Rogue keep their type-6 slot 35 although its file bit 0 is clear (Q376, combat-approach-and-victory.md §7). The earlier "Present flag" wording meant this runtime bit.
