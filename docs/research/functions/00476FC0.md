It indexes the state table as `0x006DA8B0 + 25 * stateId` with the handler at `+0`, which is how the table's frame was pinned (creature-state-table.md §2). Outside category 2 it runs the current category's update hook (`0x0069969C + cat * 0x40`); inside a walk it runs the hook only when the resume slot `+0xDF` and the saved caller `+0x40` share a category, and a hook returning 0 sets state 1 and ends the tick (state-categories.md §5.1, CONFIRMED). After the suspend countdown `+0x44` and the hook, a non-worker runs the need-anger routine `0x00478D00` and the needs routine `0x00477C20`, then the unhappy or angry chooser; the happy chooser belongs to idle state 89 instead (creature-needs-routine.md §1, idle-fallback.md §1).
