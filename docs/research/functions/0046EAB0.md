Order: the Heart push; the Torture snap, Temple splash and Combat Pit scatter; the flyer's descent; the predicted-at-floor gate; the landing work.
- Heart push (room type 5, 0x0046EAE4..0x0046EB4A): runs when the state's +0x1C is 1, the room is a Heart, the tile is not an inner Heart tile, and definition +0x686 bit 0 or bit 7 is clear. It finds the room's first object of type 0xD, takes Math_Atan2 of (creature minus object) and adds a physical velocity of magnitude 0x8000 away from it (Thing_AddPhysicalVelocity). Age 1 is the first update after the turn the state was set (255's note, not re-read), so this runs on the landing update, not the drop turn.
- Temple (type 0xD): the cell is a Temple floor slot and unsigned (Z minus floor height) is below 0x1000, so a Z below the floor wraps and fails. It calls 0x004F1940 on every update of 76 while that holds; that is cosmetic, not the sacrifice. The landing branch then skips the thud sound 0xF6 for a Temple floor slot.
- Torture Chamber (type 0xC), every update: Creature_StopMoving (0x0046EC8F, a new unfinished self-route), +0x104 and +0x108 cleared, x and y snapped to the tile's centre (tile * 0x1000 + 0x800) keeping Z (skipped only when they already equal it), LastPosition (+0xF6..) written. A drop on a wheel tile gets a new self-point each update, so the steering turn also happens on the landing update.
- Combat Pit (type 0x10, floor slot), every update: x = (centre & ~0xFFF) | random(0x1000), y likewise, from the world stream (Random_Next with line numbers 0x6D and 0x6E); Z unchanged; LastPosition written. A one-turn fall runs the handler twice (drop turn and landing turn): four draws.
- Flyer (vtable +0x88, Creature_IsFlying): Z lowered by 0x800 on each call, before the gate; the gravity pass is bypassed (record 0048ED40). From 0x2000 over a floor at 0 the fourth update lands.
- Dying branch (the gate says at floor): sound 0xF6, SetState(1), end any running action, then, when +0x3E6 bit 21 (0x200000) is set, Creature_EnterDeathFall 0x00459560 and return, skipping the stun and room-drop code. Bit 21 is set by 0x0048B770 and cleared by 0x0048B860; Hand_PickUp refuses a creature with it. Who sets it while a creature is in 76 was not found, so when this branch is reached in play is unknown.
