Thiscall on the room manager. It refuses when the in-use count (+0x12) has reached 0x2A0 (672). It takes either a reserved id (+0x16/+0x1A, then cleared) or the free list's head (+0x10). It calls Room_Construct (0x004E3800) with the owner and type, its only caller. On success it moves the room from the free list to the in-use list (head +0x0E, node +0x1F/+0x21), increments the count and writes the id out. Its caller is Room_StartWithTile (0x004EC5A0, the call at 0x004EC5B5). Read by decompile only, hence LIKELY.
