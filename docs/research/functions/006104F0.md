Sets group+8 item pointer, skips itemCount*42 bytes, then0x00610590 per item. Afterwards each link target index becomes groupItems+(index-1)*42.

Item layout as the in-place block gives it (read 2026-11-13; the loader reads the file payload after the 24-byte header in one piece, so every offset is the file's, from the item header start): +0 sound count, +4 link count, +8 sample pointer (written here), +0x0C/0x0D volume, +0x0E/0x0F pitch, +0x10/+0x12 delay words, +0x22 a float (the maximum audible distance for SoundInstance_BindVoice 0x0060CDB0, in mixer units), +0x26 link pointer (written by 0x00610590). The loader never touches +0x22, and SfxMap.cs keeps item bytes +0x22..+0x25 as bytes 26..29 of its `Unknown0x08` block of the item (not of the group, whose 12-byte block ends at +0x13).
