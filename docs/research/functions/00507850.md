Read whole 2026-10-04 (Q271). It writes the base vtable and the thing's id at `+0x04`. While `0x006F2540` is set (the save restore) it takes the forced id `0x006A4820` and clears the flag; otherwise it takes the first empty slot from the cursor `0x006A481C`, wrapping at 0xFFF to 1, and advances the cursor. `0x00507A30` resets the cursor to 1; `GameAction_LoadLevel` calls it at `0x00513994` just before `Players_Create`, so the seven players get ids 1 to 7, which is why a player's `TagId` equals its `Number` on a level load.
