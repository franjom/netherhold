Success clears the task clock, sets the next task bits and spends one allowance. On failure it restores +0x76 and compares the current direction (+0x00 bits 8-9) with the preferred one: bits 10-11 (the defend direction) for a room id below 6 at +0x98, else bits 12-13 (the open one). Current == preferred: +1. Current == preferred+1: current-2. Current == preferred-1: current-1.
