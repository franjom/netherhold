Called from the creature update just before the needs routine (creature-needs-routine.md). No lair: def+0x6C1, only when no bed and the Lair room type is available; no food: def+0x6C3, when HungerNeed reaches level-scaled HungerFill and a hatchery is available; no pay: def+0x6C5, whenever WageOwed and level-scaled Pay are both non-zero, with no treasury clause (ADR-0079). It returns at once when the current state carries bit 1 of the state flag byte, which all eleven captive states carry (Q185). Read from the binary and accepted in ADR-0079 but not marked confirmed, hence LIKELY; CreatureAngerRules.PerSecond mirrors it.

It also returns at once while +0x3E6 bit 3 RebelActive is set (0x00478D4F), so a rebel accrues no need anger during the countdown.
