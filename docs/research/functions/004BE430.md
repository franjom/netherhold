Finds the spell's row in the player's sorted 17-byte spell table (count +0x6E, rows +0x72, id byte +0). Row dword +5 is the turn of the last cast: zero returns 100. Otherwise elapsed = World_GetGameTurn (0x00517490) - stamp; elapsed >= the definition's +0x3E (cooldown in turns, KEEPERSPELLS file 0xCC, keeper-spell-thunderbolt.md) returns 100. Else it computes (0x64000 / (cooldown << 12)) in 20.12 fixed point and multiplies by the raw elapsed (0x00441990 divide, then multiply), so the result is floor(floor(100 x 4096 / cooldown) x elapsed / 4096). The caller 0x00412FC0 keeps the low byte. Ours: AvailabilityState.LastCastTick and KeeperSpellDef.CooldownRaw (the cooldown KeeperSpellRules.CanCast computes).
