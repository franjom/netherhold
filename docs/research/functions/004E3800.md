It indexes the per-room-type handler table at 0x006a1e9f (base + typeId x 41, guarded 0 < id <= 26) at 0x004E3993 and loads slot +0x01, the type's own constructor, which for a Portal or Hero Portal is 0x004DBB90 (zeroing the generation tally). The table, its ten slots and all twelve indexing sites are marked CONFIRMED in portals-room-handler-table.md; DECISIONS.md ADR-0086 amendment 1 names this function as the constructor that calls slot +0x01. Not mirrored as one routine in src/: our rooms are derived from tiles rather than constructed.
