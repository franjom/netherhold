World vtable 0x0066E3EC slot +0x2C4. Calls slot +0x1FC for bounds, then
+0x1D8 for the cell, and returns (cell.word8 & 0x2000) >> 13. Other-player
trap and door markers use this predicate; the creature marker path reads
the same bit as byte +9 bit 0x20 after its position-based tile lookup.
