A thiscall on the target with three stack arguments (delta, source, mode); mode 0 is ordinary, and a non-zero mode lets the dying countdown pass the early return for a CreatureDying creature. It first writes the source to thing +0x36 for every class; delta 0 then returns health unchanged. Objects (class 2): type 94 (Arch Pillar) returns 0x004DA200(delta, source) (Player_ModifyHeartHealth, win-and-defeat.md §3.1); any other object returns unchanged on a negative delta unless its definition (+0x12D) +0xF4 has bit 21 (Damageable). Every class other than creature (object, shot 1, trap 3, door 4, dead body 6) then takes +0x40 += delta flat, with no multiplier, clamp or death handling here (0x004B324A). For a creature with a negative delta it refuses def+0x686 bit 14, dying, OnlyAttackableByHorny, IsHorny and InHand targets, then scales by a multiplier in 128ths (frozen 160, armoured or possessed -64, owner byte +0x1095 -8 each, stunned +128, pit fighter per variable 239). At health <= 0 with GenerateDeadBody it sets health to CreatureDyingStateDurationSeconds x ticks and body bit 21; the death block also reaches vampire reincarnation 0x0048FFC0 (Q111). At the end, for classes 0, 4 and 3 only, +0x38 and +0x3C = now + 3/4 of world+4->+8. About 40 callers: the swing, shots, spells, prison, torture, needs and the heart among them. For a creature, any non-zero delta that reaches `0x004B2DE7` (mode 0 with dying bit 21 returns first) calls `+0x74` at `0x004B2E08`. A BeingDragged creature (`+0x3C7`) gets its health back unchanged (`0x004B2E0D`-`0x004B2E19`), whatever the sign and including the dying countdown's mode 1. Built across StatusEffectRules (the creature damage branch) and CreatureDeathRules (the death block, Q303).
