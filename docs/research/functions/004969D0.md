Read whole by decompilation and instructions 0x004969D0-0x00496A18. It delegates to 0x00496700; success writes the supplied byte plus one to creature+0x3AE. A supplied count below two clears creature+0xF1 bit 0. Tremor passes one, so its count byte is two but the animation is nonlooping. It returns success only when the delegate succeeds.
