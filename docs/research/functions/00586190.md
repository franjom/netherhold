Not a Ghidra function (decompiled with ForceAt). Without 0x300 each submesh goes to 0x00586A70. With 0x300 the overlay material (item +0x24, through 0x0057C780) at frame fraction item +0x28 is resolved too. With 0x200: a base whose render state lacks 0x200 is queued once with two stages (base, overlay); otherwise base and overlay are queued as two primitives. With 0x100 alone only the overlay is queued. The control flow is read; the queue 0x007820A8 consumer and stage blend are not.
