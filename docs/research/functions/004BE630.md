Statistics part read whole 2026-10-26 (`0x004BE630`..`0x004BEF0F`), with the score sum. It returns at once when `+0x19A` is already set (`0x004BE650`), so it runs once per player. Then: status = argument; `+0x156` = `0x004BFE00` (dead: overwritten at `0x004BEF09` by `+0xB3F` DungeonArea before the copy); `+0x15E` = CurrentMana `+0x82`; `+0x166` = `+0x16` (creatures owned); `+0x16E` = `0x004BFEA0` (mean creature level, 20.12); `+0x17F` = game turn / TicksPerSecond `0x006F2590` (0 when that is 0). It counts the things of list `+0x0A` with type 117..129 into byte `+0x183`, then `+0x184` -= `+0x183` and `+0x185` -= byte `0x00759B7C`, each floored at 0. The dying-creature pass `0x004BE98D`..`0x004BEA3A` walks every other player's creature list (`+0x06`, next `+0x10`): a creature with `+0x3E6` bit `0x200000` whose `+0x36` is this player's tag adds to `+0x14A` when owned by the hero player `[0x006F254C]` (plus `MpdScoreHeroKilled` in mode 4 for Number >= 3), otherwise to `+0x146`. Status 3 writes `+0x172` = 0 (`0x004BEB6C`) and status 2 writes 1 (`0x004BEDA2`); both then store the rank of `0x004C0280` through `0x00561E90` (`0x004BEEE9`); status 1 skips both. Shared tail `0x004BEEEE`: `+0x156` = `+0xB3F`, then `0x00561E00` copies the block to profile `+0x8DD` (`0x004BEF0F`). Modes 1 and 4 go to `0x004BF211`: weights 1000, 40, 50, 5, (`+0x152` unweighted), 5, 1, 2, 5, 20, 40, 50 over `+0x142`..`+0x16E` (training as int x 50 + trunc(hundredths x 50 / 100)); mode 4 stores `0x00759C4B`, mode 1 writes Total Evil Rating through `0x00561BF0` (`0x004BF329`). Modes 2 and 3 take the alliance loops instead (Q359, win-and-defeat.md section 7, built as VerdictRules.End). The campaign arms (status, attempts, Transfer ID, secret/special, finale) are local-player gated (`0x004BEAC2`, `0x004BEBCD`). Callers include the player trigger arms for actions 10 and 11 (`0x004C8662`, `0x004C8675`). What modes 1 and 4 are is STRONGLY INFERRED (campaign, My Pet Dungeon). The profile status/branch subset is built in CampaignProgression; the statistics block beyond GoldMined, HeroesDestroyed and ItemsManufactured is not built.
