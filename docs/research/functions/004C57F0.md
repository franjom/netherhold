Arguments: room type, the rectangle's corners and a caller array. First pass: each rectangle tile that is water (0x80) with room flags +0x43D bit 0, or lava (0x100) with bit 1, and that world slot +0x22C accepts, is marked. Then passes repeat until one marks nothing: an unmarked such tile with an orthogonal neighbour inside the rectangle already marked is marked. Returns the count.
