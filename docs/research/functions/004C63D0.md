Receiver ECX is the player; one out pointer. With a nonzero room count (+0x10F9) it draws random(count) from the world stream at 0x15A0 (line 0x25B) and steps the list that many rooms; the loop continues past a bridge (8, 0x11, 0x16) with the counter going negative, so when the drawn index is a bridge it walks to the end and returns 0 without a room. A drawn non-bridge room is returned with 1. A zero count returns 0 before any draw.
