Its whole body is a call to the current-action test 0x00496D00, with that result returned; a false result drops the creature to state 1. The state table points six states at it: 95 (eating, wait out the meal animation), 211 and 260 (celebrating), 252 (stand down after the alarm, action 79), 264 (stunned) and 268 (destroying rooms). combat-approach-and-victory.md marks it CONFIRMED (binary), and combat-alarm.md section 3 describes the same behaviour for state 252; FearRules (252, ADR-0580), DropDeliveryRules (211) and TremorRules (264) build it.

For state 264, a false result reaches the dispatcher's state-1 fallback.
The later movement gate reads the new state and skips steering because
idle 1's flags are zero; see 0x00488930. Category 7 has no leave hook and
idle category 1 no enter hook (state-categories.md section 7.1), so this
transition supplies no category-hook route reset.
