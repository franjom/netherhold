Blocked when player+0x76 bit 0x400000 is set. With an existing alliance it queues action 122 (break, 0x00513F60). Otherwise, when the selected player's offer byte toward the local player is set (selected player +0x1B6, indexed by the local player's compact number +0x10FC), it queues 123 (make, 0x00513FF0): accepting their offer. Otherwise it queues 118 (0x00513EE0) with flag 1 when the local player's own offer toward them is clear and 0 when set, so 118 offers or withdraws. The packet's word 0 is the selected player, word +0x10 the local viewer. This callback is the only place the original enforces consent: the make handler itself checks no offer.
