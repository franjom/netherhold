A definition flagged 0x4000 (IsHorny) takes a separate routine; three states return at once and two take a short path. The LastSlapTick window (creature+0x4BB plus variable 19) guards only the knock-back impulse, so there is no cooldown on the slap itself; then it writes LastSlapTick, charges AngerSlap, raises speed to 150 % if SpeedChangeTimer is zero, and sets WorkFasterTimer to a hardcoded 100 ticks (25 s), which is why slaps do not stack. It is also the only entry to state 77 (via 0x0048BA06), fires creature event 5 and player event 0x3C, and stamps the research slap window. The handler order is a binary read; the ten-point, non-stacking, 25-second bonus is owner-confirmed, the no-cooldown reading is STRONGLY INFERRED (hand-of-evil.md summary). SlapCreatureCommand mirrors it without the knock-back.
