A definition flagged 0x4000 (IsHorny) takes a separate routine; three states return at once and two take a short path. The LastSlapTick window (creature+0x4BB plus variable 19) guards only the knock-back impulse, so there is no cooldown on the slap itself; then it writes LastSlapTick, charges AngerSlap, raises speed to 150 % if SpeedChangeTimer is zero, and sets WorkFasterTimer to a hardcoded 100 ticks (25 s), which is why slaps do not stack. Its one SetState, the shared tail at 0x0048BA06, takes its state by the creature's room (+0x3B9), read 2026-10-01: in a room the slapper owns, type 10 sets 67 (0x0048B9DB), type 11, a Prison, sets 120 (0x0048B9C3), type 12 takes damage and returns, any other type sets 77; in another keeper's room it sets nothing and skips the events; with no room, states 0x43, 0x78, 0x84 and 0xC5 return without any effect (byte table 0x0048BD9C, entries 0x0048BD88), and the rest set 77. It is the only entry to 77. It fires creature event 5 and player event 0x3C, and stamps the research slap window. The handler order is a binary read; the ten-point, non-stacking, 25-second bonus is owner-confirmed, the no-cooldown reading is STRONGLY INFERRED (hand-of-evil.md summary). SlapCreatureCommand mirrors it without the knock-back or the state change.

`NumberOfSlaps` (read 2026-10-04, Q278): both counting sites add 1 to `[creature+0x2A]+0xEE6`, the slapped creature's owner. The second argument, a player record, gives only the damage source's `TagId`.
- States `0xD1`/`0xFF` count, fire the events and return early.
- The main path counts after the SetState tail.
- No count: `IsHorny`, states `0x4C`/`0x65`/`0xC1`, a held room (`+0x3B9`) the slapper does not own, with no held room states `0x43`/`0x78`/`0x84`/`0xC5`, a refused SetState, room type 12 (damage only).
- Every no-count path but type 12 returns before the damage, anger and bonus too.

Built in HandSystem.Slap with these arms on HeldPlace (ADR-0373). Ours makes no state move, so a slap DK2 counts only when the move is accepted is always counted; a Horny's state 242 arm is not built (ours slaps it in full, uncounted).
