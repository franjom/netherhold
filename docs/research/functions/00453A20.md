Thiscall on the 16-byte map cell, one byte argument, the room type. It returns 0 for a cell with no room, else compares the room's type byte with the argument. It has dozens of callers. Vampire_Reincarnate (0x0048FFC0) calls it with 13 (Temple), then Room_IsFloorSlot (0x00454110), to refuse a reincarnation on an interior Temple cell. Read by decompile only, hence LIKELY.
