Read whole. Record flags at +0xC:
- **Bit 0, RLE into the 0x007A5C8C scratch buffer** (grown to the unpacked size +8). The nibble reader 0x006340B0/0x00634090 and the writer 0x00634040 both go high nibble first. A non-zero nibble is one pixel. A zero is followed by a count; a count of 0 ends the glyph, otherwise a value follows, repeated count times.
- **Bit 1, 1-bit pixels.** It reads unpacked-size * 2 bits from mask 0x80 down, writing 0xF or 0.

A glyph whose character is 0x20 only reports the pen. Otherwise it draws at the pen plus the signed bytes +0x14 and +0x15, sized from +0x10 and +0x12. It then picks one of five blitters (unread) by the surface pixel format, which 0x0052D3E0 tests.

0x00634040 writes a high nibble as a whole byte (value << 4), which zeroes the low nibble; only the low nibble is ORed in. So the 177 shipped RLE glyphs that end one nibble short of an even w*h end with a clear pixel, not with stale buffer data.

That pixels run on across rows unpadded is STRONGLY INFERRED from the data: every unpacked size is ceil(w*h/2). The blitters, which receive the stride (w+1)/2, are unread.
