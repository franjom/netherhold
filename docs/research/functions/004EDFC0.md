The floor pass runs only for a room with SpecialTiles and a non-zero first object id: slots are tiles whose eight neighbours are the same room, object ids 0 to 3 are the floor choices (only 0 to 2 when SpecialWalls also uses index 3), Guard Room, Workshop and Casino keep one checkerboard parity (0x004EF5E0), and the type comes from a selector seeded by tile coordinates (seed x 0x0019660D + 0x3C6EF35F, rotated right 13, moduli 0x2286 and 0x16F2), so a rebuild reproduces the same furniture. The wall pass uses ids 3 to 5 on straight wall runs of at least three tiles, every other tile from the first eligible one in slab-list order. 0x004ED1A0 runs it after every tile insert, and its one call to the door routine 0x004E32C0 at 0x004EE045 moves the Prison door as the room grows (jail-break.md §1, verification-2026-09-26.md). The docs read the passes from the binary without marking the function itself confirmed, hence LIKELY. Built as AutoFurnitureSystem with AutoFurnitureRules (tile-level, rooms sorted rather than in insertion order) and JailBreakRules.DoorTile.
