The minimap's known/unknown test: the unknown colour unless the explored bit (`tile+8` word bit `0x2000`) is set, or the scanned bit (`+0xB` bit `0x40`) is set on terrain with flag `0x01000000` (`RevealThroughFogOfWar`) (fog-reveal-sources.md §1). In its fogged branch it tests exactly one room type, the Dungeon Heart (type 5), not the Portal, so it does not explain the portals the owner saw dimly through fog (fog-of-war.md §9.4, Q197). Read from the binary, so LIKELY; the two docs agree. Fog itself is built (FogOfWarSystem), but this renderer routine is not mirrored.
