It has exactly two exits, success at 0x0051988C and the "Unhandled Trigger When" failure at 0x00519893, so whether a type succeeds is static per type. - **Action 49** (slot 24, `0x005197F7`): byte 1 the player, the dword at +4 a one-based tile (x = low word - 1, y = high word - 1). A null tile, a tile with no room (word +2 & 0xFFF zero) or a room already owned by that player returns 1; otherwise a direct call to `Room_TransferOwnership` 0x004E5650 at 0x00519860 (not the applier 0x004E5300), so the room's health is not reset. The player record is not tested for existence. Returns 1. Built as `TriggerExecutor.ChangeRoomOwner` (ADR-0760); ours also skips an off-map tile and a player the level lacks.
- **Action 51** (slot 25, `0x0051986C`): byte 0 == 1 sets world `+0x72A1` bit 2, any other value clears it; returns 1. The timer-speech function `0x004B9740` is what reads the bit. Default: world initialization 0x005099A0 reads +0x72A1 at 0x00509CD9, ANDs it with 0xF7, ORs in 0x07 and stores it (0x00509CE5), so bits 0 to 2 are on and bit 3 is clear until an action 51 changes bit 2.
- **Type 5** (slot 3) is the bare success exit `0x0051988C`.
