cdecl (centre float[3], radius, out int inside). Four planes through the eye, normals as three floats at 0x00760B70, 0x00760B38, 0x00760B18 and 0x00760B28 (no distance term); for each it takes d = n . centre and returns 0 when radius + d is negative (sign bit). No near or far plane is tested. When centre z minus radius is not negative and radius - d is not negative for all four (the sphere wholly inside), it writes 1 to the out flag; else 0. Returns 1. The static and animated mesh draws pass the KMF bounds centre through the view matrix at 0x00760AB8 and the radius as the mesh's bounds scale [EDI+0x20] times the draw's scale [ESI+0x58] (0x00580F6E..0x00580F87; the animated twin at 0x005849C7); a 0 skips the draw (0x00580F91 to 0x00581B64), so the pick circle Render_ProjectSphere (0x00575F10, called at 0x00580FA7 and 0x005849E7) runs only for a sphere that passed. Other callers: 0x0058624F, 0x00587122, 0x0059C1C1 (not read). The remake's pick culls the renderer box against six planes instead (ViewFrustum.Excludes(PickBox), carried over from Unity).
