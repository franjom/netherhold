The Variables dispatcher 0x0051AA90 pairs kind 0x41 (the table entry at 0x006A616C) with this handler (0x006A6170). The record holds the stat id at +0x14, the value at +0x18 and the level at +0x1C. The handler writes the value's low word to 0x006F261F + 18 * statId + 2 * level, with no range check. Readers take [0x006E4154] (= 0x006F2550) + 0xCF + 18 * statId + 2 * level, which is the same cell. So file stat s at level L is what the runtime reads for stat s at level L, with no offset in either index. For MaxGoldHeld (stat 6) that is +0x13B + 2 * level, the row read by 0x0048AB60, 0x00464360 and the gold block of 0x00488930. The shipped row (GlobalVariables.kwd; no level file carries CreatureStats) is 105, 110, 115 and 120 for levels 2 to 5, then 120 to level 10.
