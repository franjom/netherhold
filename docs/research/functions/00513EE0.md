Dispatch slot 0x76 (game-actions.md). The packet's word 0 is the target player, dword +4 a flag, word +0x10 the issuer (the layout Hud_RequestAllianceChange 0x00425B50 builds). Flag set: the issuer's byte at +0x1B6 indexed by the target's compact number (+0x10FC) becomes 1 and message 0x52 kind 1 goes to the target. Flag clear: that byte becomes 0, no message. So +0x1B6 is the per-player alliance-offer array beside the alliance array +0x1AE. No check of the issuer or the target beyond the dispatch.
