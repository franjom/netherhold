transformed by matrix 0x00760AC4. With origin at 0x00760AB8..0x00760AC0,
intersection parameter is (planeZ-originZ)/directionZ. Output +8/+12 retain
float XY; +0/+4 use the native float-bit integer conversion. No division-by-zero,
behind-origin or finite-value guard appears in the complete body. The footprint
caller consumes float XY and supplies planeZ=-1.
