The receiver is the task pool. The entry is pool + id * 36. Its allocated
byte +0x23 must be nonzero, id word +0x21 must equal the supplied id, and
kind byte +4 must equal the supplied kind. Reusing the same id for another
kind fails; reusing it at another position with the same kind passes.
