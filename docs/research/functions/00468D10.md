Centred on the imp's position, it tests the own tile unfiltered, then rings at each Manhattan distance, four sides walked clockwise corner to corner from a start side given by the chooser `0x00469340` (claims, drop scan, Tier B) or `rand(4)` (kinds 6, 7, 8, 16); a tile is handled only when byte `+0xB` bit `0x20` is clear or it carries a dig or mine task (imp-claim-path.md §2). Radius is `0x7FFFFFFF` for Tier A, step (a) and Tier B, and `0x2000` (rings 1-3) for the drop scan; it never looks past the first accepting tile. The diamond shape was found by emulating its bytes and then confirmed from the pointer steps (imp-task-priority.md §2.2, imp-claim-path.md §2).
