Dispatch slot 0x7B. Clears both players' offer bytes (+0x1B6, each indexed by the other's compact number +0x10FC), sets both alliance bytes (+0x1AE), posts message 0x52 kinds 2 and 3 to the pair and 0x53 to every other non-neutral player. It reads no offer before writing, so consent is enforced only by the sender: Hud_RequestAllianceChange 0x00425B50 queues 123 only when the target's offer toward the local player is set. Our AllianceSystem mirrors the symmetric write; it does not model the offer array or the messages.
