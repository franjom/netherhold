Arguments (x0, y0, x1, y1). Starts from the edge 0x004C9C30 finds leaving (x0, y0) toward (x1, y0). Turns through the triangles on the inner side; a triangle's far vertex that lies on none of the rectangle's four lines is removed by 0x004CAF40 and then 0x004CB170 (degree 4) or 0x004CB8C0 (3), and the walk restarts from the start edge. It crosses only edges without the constraint bit (+0xD bit slot + 3) and stops when it comes back to the start triangle. Each triangle passed has its region id (+0xE >> 6) cleared, decrementing that region's count at 0x006E96C8 and bumping the free count. Called by 0x004CE770 for any partial rectangle larger than one tile.
