Thiscall on a player, RET 0x14: (creature, type, &point, &out, options). Walks the room list from player+0x36 (next at room+8, newest first) for room byte +0x18 == type; type 11 also needs room +0x59 nonzero. Distance is to the tile centre of NavigationPos (+0x2B/+0x2C), squared per axis and shifted 12; a candidate must be strictly nearer than the best so far and pass Route_IsPointReachable (0x00471630 on creature+0x24E with the options). Returns 1 with *out set when one is found. Read for state 96 (Hatchery, type 4).
