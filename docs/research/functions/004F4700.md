Read 2026-10-01 by disassembly (`0x004F4700`–`0x004F4728`). ECX the room. Type `+0x18` = 5 with `+0x9A` bit 0 clear: `[0x006F25A8] << 4` (16 × 1000 = 16,000). Otherwise `+0xA7` (size) × `[0x006F25A4]` (3000). The store chooser `0x00464400` takes a room only while `room+0x49` is below this, so a Heart counts as having room until it holds 16,000; state 29 (`0x00466AC0`) uses a different capacity for the same Heart (16 × 3000). Ours tests the same through the tiles' space in `TryRouteToSomewhereItFits`.
