The loader reads a 0x54-byte Good record, converts both coordinates to tile * 0x1000 + 0x800 and passes that point to 0x004B78D0. It has no room furniture relocation branch. ObjectiveTargetPlayerId is mapped from nonzero file byte to player index minus one; Objective and action point are passed to 0x0048BE20. Then the record's Flags byte (+0x43) goes bit by bit to the +0x46F setters (0x0048DF10 bit 0 ... 0x0048E030 bit 7), and its Flags2 byte (+0x53) to the party spawn's four: bit 0 0x0048E090 (DestroysRooms), bit 1 0x0048E0B0 (IsTool), bit 3 0x0048E0D0 (IsMercenary), bit 2 0x0048E140 (DieInstantly, +0x3EA bit 11). With +0x46F bit 7 set it collapses the creature at once (0x0048F1D0 health cap, then Creature_Collapse).
