Fastcall on the player. It walks the keeper's room list (head +0x36, next +0x08) and, for each room whose type byte +0x18 is 2 (the Lair), adds the unsigned 16-bit difference of capacity +0x67 and used +0x6B. It then walks the keeper's creature list (head +0x06, next +0x10). For each creature whose lair link word +0x3B7 is 0 and whose definition (+0x370) names a lair object (+0x771 non-zero), it subtracts that object definition's byte +0x114 (room capacity; 1 for every shipped bed), looked up through the object table's vtable +0x188. It returns the signed total. It does not read TimeSleep. Callers: Portal_PickCreatureType 0x004DBF90 and Player_UpdateEntranceAttractionNotice 0x004DBD90, which both skip their whole type loop when the result is below 0, and Portal_TrySpecialArrival 0x004DCF50 (multiplayer).
