Read 2026-10-04 (Stage 8, ADR-0350). Fastcall on the player. Pass 1 tests each entry with 0x004C30F0. Pass 2 reads each entry through 0x005070A0: a kind below 1 or above 4 is taken at once; kinds 1-3 are skipped; kind 4 is taken when 0x004BAFA0 returns 3, 0x004BB0D0 returns 0 and the spell record's byte +0x4B (bonus shot) is non-zero. So Summon Horny (5) and OneShotReaper (14), which have no bonus shot, are never upgrade targets. ResearchTreeRules.ChooseTarget follows both passes.
