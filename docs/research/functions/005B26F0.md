Saves the control word, clears rounding control and sets precision control to 64 bits (0x005B2706..0x005B2718). Flag bit 7 enables alpha, bit 0 clear a mask, bit 4 selects the 32-bit block routine 0x0065CA50 over another one. Every shipped entry has bit 4 set and bit 0 set. Our code mirrors the block walk and precision for flag 0x75/0xF5 only; the 16-bit, mask and non-bit-4 paths are not mirrored.
