The handler table makes it the only caller of slot +0x09 (indexing site 0x004E44BE) and calls that slot "a tile/effect pass"; for Portal and Hero Portal the slot holds 0x004DCD20. combat-pit.md §1 places the Combat Pit's slot +0x09 handler 0x004D7E00 after any of the three rebuilds that change a room's tiles (0x004EC900, 0x004ED1A0, 0x004ED440), which is where this dispatcher is presumably reached from; all three call it (0x004ED76C, 0x004ED2D8, 0x004ECB1D). It first writes the game turn to room+0x9F (0x004E4491), GameTickLastOnChangeSize, which the finders' four-second full-room tests read. The size-change stamp is mirrored by SlabChain; entrance light allocation is not.
