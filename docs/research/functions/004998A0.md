The swing calls it for each class arm (creature, door, trap, object), passing the attacker's attack type and one byte read from the target's own definition (the possessed act calls it for three objects). It linearly searches the .data table at 0x0069DA38 (37-byte records keyed by the attack type at offset 0, terminated by 0xFF), then a jump table at 0x00499A24 picks one of seven arms by the surface byte, each reading a sound word and an effect id (u16 each) from the record. The damage register is untouched, so it is not the resistance step (combat.md section 6.1). It asks effect 0xED, the pair's effect and the pair's sound; see the 2026-11-03 History line and sound-effects-combat.md section 5.
