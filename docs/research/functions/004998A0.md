The swing calls it for target kinds 2, 3 and 4, passing one byte read from the target's own definition. It linearly searches the .data table at 0x0069DA38 (37-byte records keyed by the attack type at offset 0, terminated by 0xFF), then a jump table at 0x00499A24 picks one of seven arms by the second argument, each reading a pair of u16 values from the record into an out-pointer; it returns with RET 0xC. The damage register is untouched across all three calls, so it is not the resistance step (combat.md §6.1, restated as step 4 of combat-damage.md). The mechanics are a binary read; the purpose, hit presentation (which effect an attack makes on a surface), is only the doc's best guess, since the values sit in a 170-450 band.
