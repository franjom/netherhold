Arguments x, y, value; copies bit 0 of value into byte +0x0B, then calls 0x004522A0 on every in-map tile of the 3x3 block. Five callers: the level loader (0x0050BA11, value 1, for doors whose definition +0x8B has 0x20), state 37 (0x00467604, value 1, Secret Door), 0x004A55F0 and 0x004C3670 (value 0) and 0x004A5290 (a computed value, unread). The byte scans found no other writer of bit 0 besides state 39's clear at 0x0046781D.
