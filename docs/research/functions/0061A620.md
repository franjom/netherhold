Read 2026-11-13. Thiscall on the QMixer backend (vtable 0x006742D0). Runs 0x0061A500, QSWaveMixInitEx and QSWaveMixActivate (0x0061A63C, 0x0061A64C), QSWaveMixOpenChannel (0x0061A660), then calls its own slot +0x70 (0x0061AE30) with handle 0 and the floats (1.0, 200.0, 1.0). A failure anywhere stores -1 in the result, which makes SoundDevice_CreateBackend 0x00618040 give up. The call passes handle 0 and flags 0, so QMixer applies the mapping to one channel at most, channel 0 ([qmixer-distance.md](../qmixer-distance.md) section 2); it is not a mapping for every channel. A fresh channel holds the DLL's template defaults 1.0, 100.0, 1.0 (0x18027158, QMIXER.DLL address) and a reused channel keeps its last voice's mapping. A head-relative voice sits at (0, 1, 0), within distance 1, so it plays unmapped at full volume whatever mapping is in force (STRONGLY INFERRED, reviewer re-derived).
