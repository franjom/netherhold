By the mixer's mode byte at `+0x34` it ORs bits into block `+0xC` (0x0060F077..0x0060F08D): mode 2 with mixer `+0x8` bit 3 ORs only 0x2; mode 3 with that bit ORs 0x10 then 0x2; it always ORs 0xC0.
