Called by the dispatcher `0x00476FC0` for every non-worker each turn; a return of 1 runs the new state's handler at once and skips the mood chooser. It returns 0 for a group-7 state (a need already being attended to), otherwise asks each need's transition test for its own category (Eating 8, Sleeping 9, Payday 20; all three masks `0x800A3C3B`) using the category resolved through a walk (creature-needs-routine.md §2). Hunger comes first and each block returns on success, so a creature leaving to eat does not also consider bed that turn (eating.md §3).
