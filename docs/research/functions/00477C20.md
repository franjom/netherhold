Called by the dispatcher `0x00476FC0` for every non-worker each turn; a return of 1 runs the new state's handler at once and skips the mood chooser. It returns 0 for a group-7 state (a need already being attended to), otherwise asks each need's transition test for its own category (Eating 8, Sleeping 9, Payday 20; all three masks `0x800A3C3B`) using the category resolved through a walk (creature-needs-routine.md §2). Hunger comes first and each block returns on success, so a creature leaving to eat does not also consider bed that turn (eating.md §3). The hunger clock is a stamp: `rate + [+0x48] <= now` compared unsigned (`0x00477D13-0x00477D1B`), flag bit 3 skips it (`0x00477D21`) and the stamp moves to now (`0x00477D2D`); ours runs it at the top of the eat step, ahead of the attempt and the state handler (`CreatureEatSystem.Clock`, `EatingRules.Tick`, ADR-0782). The attempt's retry stamp `+0x50` (`0x00477DAE-0x00477DBC`) is not built as a stamp: `FoodAttemptTicks` counts down, and neither the clock nor the attempt is gated by the keeper-only entry in `0x00476FC0` (Q674). It is also the only reader of `CannotSleepModifyCreatureHealthPerSecond` (variable 82, shipped 0): health lost per turn while the sleep latch `+0x58` is set.
