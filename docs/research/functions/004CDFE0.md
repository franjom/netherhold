Arguments (x0, x1, y). Reads the bytes of row y-1 and row y at x0, inserts the point (x0, y) with 0x004CAA50, then for each x in x0+1..x1-1 inserts (x, y) when either straddling byte differs from the last pair seen. Inserts (x1, y), then the constraint from (x0, y) to (x1, y) with 0x004CBD10. Called by 0x004CE770's partial path for the top and bottom sides; its vertical twin is 0x004CDF20.
