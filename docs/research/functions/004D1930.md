The byte lives in the grid at world +0x9F2; bit 3 (value 8) means blocked. After a changed store it calls 0x004CE770 with the one-tile rectangle, which is how the mesh follows terrain edits (navigation-mesh-and-search.md §2). Its producers are the terrain update 0x0044FC40 (solid 8, else 1, 3 or 0), the door update and toggle 0x004A66F0/0x004A6800, and the room-side wrapper 0x00454FD0; no object or furniture path writes it (Q209, STRONGLY INFERRED from the complete caller graph). The silent twin is 0x004D1970. Our navigation bytes are recomputed whole (WorldSteering.CaptureNavigationBytes), not written through a setter, so this is not mirrored.
