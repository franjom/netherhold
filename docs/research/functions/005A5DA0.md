After device and sound set-up and the one-time component setup 0x00552BE0, it chooses the start: -LEVEL/-Q (0x0075AE6B) give game mode 1 straight into a level; -PD (0x0075AE6F) mode 4; otherwise, unless -FE/-FE3D already chose (0x007962A8), it sets the 3D front end flag 0x0075AEAF, game mode 5, level name FrontEnd3DLevel, and sets 0x0075AEB7 (2D front end) when the benchmark 0x00559790 is under 240 with a 3D card or under 290 without. It then loops over components starting at 0x0070D138: slot +0x0C init, +0x14 run returning the next component, +0x10 shutdown; then 0x00552C30 and shutdown.
