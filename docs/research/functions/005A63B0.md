Logs the command line, defaults the level name to LEVEL and movies on (0x0075B170 = 1), then compares each argument. Front-end relevant: -LEVEL name and -Q set 0x0075AE6B; -PD sets 0x0075AE6F; -FE3D sets 0x0075AEAF = 1, mode 0x0075AD4B = 1, level FrontEnd3DLevel, 0x0075AEB7 = 0, 0x007962A8 = 1; -FE does the same with 0x0075AEAF = 0, 0x0075AEAB = 1, 0x0075AEB7 = 1 (2D front end); -NOMOVIES clears 0x0075B170; -NOSOUND sets 0x00796294; -NOMUSIC/-NOSPEECH call the music/speech switch setters with 0. -CHEAT sets 0x0075AE8F = 1 (0x005A6C03; EBP is 1 from 0x005A6423), an address no other byte in the binary holds, so the switch does nothing. -NOCHECKSUM clears 0x0075B308 (read by the out-of-sync test in GameSession_UpdateLoop); -NOFILECHECKSUM clears 0x0075AE57 (read by the packet header writer 0x0055EAB0). Other switches (graphics, packet record/playback, -LANGUAGE, -CDPATH) set their globals and are not interpreted further here.
