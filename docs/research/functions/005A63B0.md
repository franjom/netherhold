Logs the command line, defaults the level name to LEVEL and movies on (0x0075B170 = 1), then compares each argument. Front-end relevant: -LEVEL name and -Q set 0x0075AE6B; -PD sets 0x0075AE6F; -FE3D sets 0x0075AEAF = 1, mode 0x0075AD4B = 1, level FrontEnd3DLevel, 0x0075AEB7 = 0, 0x007962A8 = 1; -FE does the same with 0x0075AEAF = 0, 0x0075AEAB = 1, 0x0075AEB7 = 1 (2D front end); -NOMOVIES clears 0x0075B170; -NOSOUND sets 0x00796294; -NOMUSIC/-NOSPEECH call the music/speech switch setters with 0. Other switches (graphics, packet record/playback, -CHEAT, -LANGUAGE, -CDPATH) set their globals and are not interpreted further here.
