Stops when a segment is at most 0.06 draw units (one unit a tile). Midpoint moved per axis by U(-1,1) * amp * len / 2048 with CRT rand(), amp the dword 0x006BE8F0. Forks when the bolt's scale (len/4) exceeds 0.2 and the raw rand() (0..32767) is below 256/scale, so the chance is (256/scale)/32768; the fork runs to the end point jittered by the scale per axis, via 0x005A0030.
