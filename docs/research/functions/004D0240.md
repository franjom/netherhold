Decompiled 2026-10-06. Clamps the mode argument to 0..0x3FFF. Copies from x/y, to x/y and the count (source +0x1C10) to the destination block's +0x00..+0x10. For each of count-1 gate records (seven words each) it writes the point at fraction mode/0x4000 along the gate, from its first end when the record's side word is zero, from its second end otherwise; then it writes the destination as the last point. So mode 0x2000 is each gate's midpoint (computer-keeper-management.md section 7), and a one-point route is the destination alone.
