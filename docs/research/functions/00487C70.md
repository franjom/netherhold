Reached through the creature cleanup slot +0x30 (0x0048AF80) once health is below 1. It increments the killer keeper's per-victim-owner tally at player+0x19E indexed by the victim owner's Number, and, unless creature+0x3E6 bit 0x40 is set, the victim owner's creatures-lost dword at player+0x173 (player-object.md; condition type 22 reads both, Q276). Inside it the gold spill at 0x0048814B, the carried object and dragged creature releases, and the owner-list unlink at 0x00488468 are recorded (imp-mana-removal.md, creature-ownership.md), and the corpse gate tests definition bit 0x8000 with runtime bit 0x20. Credit and hero count (0x0048822F..0x0048832A, read 2026-10-23): only when health is at or below 0 (+0x40 <= 0). The credited player is the tag in the victim's word +0x36 (the source the health routine 0x004B2CE0 stamps on every health change); when that is 0, the owner word +0x28 of the first non-zero attacker scanning i = 0..7, melee +0x504[i] before ranged +0x514[i]. With a credited player and the victim's +0x3E6 bit 0x40 set, nothing is counted at all (the tally, the hero count and +0x173 are all skipped, 0x004882A9). Otherwise, when the victim's definition +0x686 has bit 8 (IsGood), the credited player's dword +0x14A (HeroesDestroyed) is incremented, and in game mode 4 (0x0075AD4B) with the credited player's Number at least 3 world slot +0x344 adds MpdScoreHeroKilled (0x006F29D5); when not IsGood and the credited tag differs from the victim's owner word +0x28, +0x146 (EnemyCreaturesKilled) is incremented instead. No owner test guards the hero count. It also fires the Killed trigger event (trigger-walkers.md). The portal tally (2026-10-04, Q508): at 0x00488150-0x00488170 it reads the creature's word +0x4EB, the portal room's tag that Portal_CreateArrival stamps. When that is non-zero and the thing's dword +0x4D is above 0, it decrements the dword (load, JBE past at 0, DEC, store), so the tally never goes below 0. Nothing checks that the thing is still a portal. EBP is 0 on both paths in (0x0048808F, 0x0048813E). Read instruction by instruction. Built as `PortalRules.ArrivalDied` with `CreatureState.PortalEntranceTile` (ADR-0358). The counter write is read instruction by instruction; the other effects are marked strongly inferred, so LIKELY. Built as CreatureHealthSystem.Die with CreatureDeathRules.LeavesBody (ADR-0277).
