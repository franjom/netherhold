Called with the keeper as this, an amount and the researching creature, from one site only (0x0047B084, the category-4 Library hook), which floors the amount at zero, so its clamp-subtract branch for negative amounts is dead (Q218). The base amount is added every tick; on ticks where turn % variable 19 is zero it adds three bonuses: the casino gate on +0x20D (never opens, nothing writes it non-zero, Q217), tortured type via 0x004F2300, and a recent slap via creature +0x4BB, with slips that make the effective rates +140%, +29% and +200% (library-and-research.md §3). After the credit it checks the target (0x004C30F0), compares cost with points (0x00507040), places a book in a Library, bumps +0x17B and resets points to zero (research-tree.md §3). STRONGLY INFERRED in both docs; built under ADR-0090 and ADR-0247.
