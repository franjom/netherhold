Scans from the head +0x801 to the tail +0x802 (wrapping past 127) for an entry whose kind byte +2 and type byte +3 match. On a match it decrements the count +0x803. A count of 0 zeroes the whole 0x800-byte ring and sets head, tail and count to 0. Otherwise a head match advances the head; a mid-queue match copies each later 16-byte entry down one slot and moves the tail back one (127 below 0), so a compaction after a wrap can overwrite ring slot 0, the cost word 0x00506B50 and 0x00506B70 read (Q618). Callers: Door_Sell 0x004C3728 (kind 0, pushed at 0x004C3720) and Trap_Sell 0x004C3AE2 (kind 1). Not mirrored: ManufactureRules keeps a list.
