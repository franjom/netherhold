Five instructions, `RET 4`: add the argument to `+0x72A2`, and store 0 if the sum is negative. Read 2026-10-04 (Q229, Q267). Its callers are the MpdScore event readers, each gated by game mode `[0x0075AD4B] == 4` and the player's `Number >= 3`. Two of them are hero killed at `0x00488303` and `0x004BEA0E`; the others are listed in player-object.md. Trigger action 7 writes the same field directly, without the floor. Not built: ours has no MPD mode.
