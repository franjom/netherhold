One straight-line run of stores from about 0x004950C6 to past 0x00495E00 (record 49 is written at 0x00495E0A-0x00495EBD) writes indices 0-80; the last byte written is record 80's last byte, which with the highest literal index any starter passes (80) fixes the extent. Among the handlers installed is the melee swing: `MOV ESI,0x498e30` at 0x0049549E stores 0x00498E30 into record 17's slot at 0x006E4385, which is how the attack routine was found to be reachable at all. It also installs the imp work handlers (dig 0x00496E00, claim 0x004974C0, attack floor 0x00497670/0x004977F0 and others). training.md §6 calls the same table an "imp task table"; creature-action-table.md shows it is the general creature action table (combat actions 16 and 17 live there too), so the narrower name is out of date rather than a real disagreement. The table layout, extent and handler installs are marked CONFIRMED (binary) in creature-action-table.md; no src/ code builds this table.
