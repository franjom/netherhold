It walks the room's auto-placed-object list, matches each object type against the definition's furniture ids, and stores the result at 0x004E4038 into the TotalCapacity field. Library, Training Room, Workshop and Casino get zero with no match and otherwise matching objects + 1; the Torture Chamber gets the plain count. The owner confirmed the Training Room arm on 2026-09-25 (a 3x3 on open ground shows 2; wall Training Targets count too). The value feeds trigger condition type 68, room capacity tests (state-category-hooks.md) and the portal attraction contribution 0x004DCE70. Built as AutoFurnitureRules.TryTotalCapacity, used by RoomCapacityRules and AttractionBudget; condition 68 is not yet wired.
