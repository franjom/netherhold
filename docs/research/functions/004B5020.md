  the position is copied, nothing is relinked, and the floor step below still runs.
- A different tile: unlinked through prev +0xA / next +0xC (a thing with no prev
  writes its next into the old cell's head word), the position copied, then
  pushed at the HEAD of the new cell's chain for its layer (cell word index
  (tile * 8) + layer at world +0x9EE): next = old head, old head's prev = this.
- Floor step (0x004B520D): 0x004545C0 gives the floor height of the new
  position's cell, stored at +0x26. Z (+0x22) < floor (signed): Z = floor; then,
  for a thing that casts to a moving thing, class +0x12 == 1 with definition
  (+0x125) byte +0x43 bit 3 bounces: vertical velocity +0x10C becomes
  (2 x +0x16F when that is nonzero, else -2 x +0x10C) / 3, truncated, +0x16F keeps
  the result (-1 for zero) and a sound (definition +0x72, 0x154) plays; any other
  moving thing has +0x10C zeroed. Z >= floor and Z > 0x3000 (JLE, so 0x3000
  stays): Z = 0x2000. Returns 1.
