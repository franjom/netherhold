The id indexes the 0x24-byte entry directly; the write needs +0x23 (allocated) non-zero and +0x21 equal to the id, and returns 1, else 0 with nothing written. So a stale id writes nothing unless it happens to name a live entry, which is what makes kind 11's unwritten id (Q496) mostly harmless.
