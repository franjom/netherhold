Tab ids FB/FA/F9/F8 select categories 1/2/3/4 (Rooms/Spells/Workshop/Creatures). Interface +0x5F is the pin count, +0x5F+c the pin rank, +0x65+4c the remembered open flag. If collapsed (+0x109 == 0) it expands through 0x004167D0(0,0) and plays 0x138 from bank [0x006AC8C4+0x30n]. Shift alone (0x005B2A50 == 1): unpinned c with count 0 -> count 1, rank 1, open c (other open panels stay); unpinned c with count != 0 -> nothing; pinned c -> count-1, ranks above drop, close c if more than one category menu is open, rank 0. Otherwise: close every unpinned category 1..4, open c. Always ends in 0x00416FD0. At most one pin can exist (the count is only ever set to 1). See tab-alerts.md section 3.
