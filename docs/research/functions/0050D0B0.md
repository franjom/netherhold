World vtable slot +0x98. Reads the world's room-definition count +0x15BC and base +0x15B4, masks the argument to a byte, starts at index min(id - 1, count - 1) and walks down (stride 0x486) until a definition's id byte +0x44D equals the argument, returning that definition; it returns 0 when the index goes negative or a smaller id is met.
