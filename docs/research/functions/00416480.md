Whole-map -1 steps to 0; the upper limit is 4. Entering 0 calls interface
+0x1EC with 0 and refreshes the map rectangle through +0x1E8. The complete
tail calls selection cleanup and conditionally clears a queued selection:
its descriptor low byte must be zero and its second byte must match the
widget callback argument. The descriptor's broader semantics remain unnamed.
