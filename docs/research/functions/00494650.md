`__thiscall (def, index)`: for `index < 8` returns `def + 0x6EC + index * 12`, else the address of a static zero triple at `0x006E4148` (initialised once behind the guard byte `0x006E4144`). Vector 0 comes from file 0xE94; vectors 1–7 from 0x127B + 12(index − 1), through the reader and definition builder (see temple-states.md section 5). State 257 takes index 2's y as its get-up step (see 00481200.md).
