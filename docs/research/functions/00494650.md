`__thiscall (def, index)`: for `index < 8` returns `def + 0x6EC + index * 12`, else the address of a static zero triple at `0x006E4148` (initialised once behind the guard byte `0x006E4144`). 257's handler `0x00481200` takes index 2 as the step a creature makes along its facing when it gets up. What the eight vectors are in the creature file is not read.
