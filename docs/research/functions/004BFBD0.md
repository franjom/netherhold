Receiver ECX is the player; one argument, the creature. When its state accessor 0x00478A20 is not already 75 it sets state 75, or 1 and then 75, returning 0 if both refuse; then clears the creature's fight and Combat Pit marks (0x0048F3F0, 0x0048B860), zeroes +0x66/+0x68, stamps +0x2CC with the game turn and fires player event 0x3A and creature event 0x41. Returns 1. The keeper's retreat and training moves call it before 0x004BC500, so a creature the hand then refuses stays in 75; ours models that only as the training moves' reading of a creature the retreat prepared (ADR-0317).

Sound (0x004BFCE2): the function ends on positional 0xC3 (slot +0x20) in the creature category (definition +0x6E3) with handle 0 at the creature position +0x1A. It plays whether or not the creature was already in state 75 (the state block is skipped then), not when both attempts at 75 fail. Most shipped creature categories have the group (creature_imp has 4 samples; firefly, Jack in the Box have none); see sound-effects.md section 6.
