The slap swing (cursor state 11, callback 0x0040E520) is requested at 0x00409497 after the slap action is posted, on an empty-handed right press with no tool mode: over hover kind 2 (an own creature that 0x004918B0 accepts; action 0x3E), kind 3 (another's creature, only when 0x0048E6A0 permits its pick-up; action 0x3E; otherwise action 0x6A and no swing), kind 4 (an object with definition flag 0x200; action 0x3F) or kind 7 (a trap whose definition byte +0xBC is 0x24 and +0x10C bit 5 is clear; action 0x40).
