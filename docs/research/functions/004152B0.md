Requests `Gui/icons/i-%d`, `Gui/icons/mana/s-%d`, `Gui/icons/lo-%d` and `Gui/spells/rt-%d` through resource service slot +0x54, each for digits 0 through 9. Paths are read from raw image bytes, not punctuation-flattened Ghidra symbol names. Runtime arrays are interface+0x12BE, +0x12C2, +0x12C6 and +0x12CA respectively. Resource totals use the first or third family; mana rates use the second.
