It asks the availability value (0x004BAFA0); if 3, it asks the Upgraded dword (0x004BB0D0) and, when zero, calls 0x004BB070(spell, 1) and posts message 0x17 to the room owner, then returns: no book. Otherwise it finds a shelf slot (0x004E1AC0), creates object 4 (0x004B7A90), tags it kind 4 at +0x14A and the spell id at +0x14E, shelves it through 0x004E12A0 and posts message 0x16.
