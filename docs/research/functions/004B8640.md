The player initialiser. It stores 1 into both words of the heart position `player+0xB43/+0xB45` (at `0x004B883E`, `0x004B8845`), so a heartless player's heart reads as (1, 1), not the origin (corrected 2026-09-26, Q372). It sets the mana-warning state at `+0x76`, `+0x9E`, `+0xA6`, `+0xB48` (warning bit enabled, removal bit clear, deadlines and stage zero), zeroes `+0x20D`, `+0x20F` and `+0x213`, and per KEEPER_AI.md constructs the player's AI object. Read from the binary in several docs, which agree; no capture confirms it. Not built as one routine: FearRules.NoHeartTile and ManaRemovalLifecycle carry the values it writes.
