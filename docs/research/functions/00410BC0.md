Whole body decompiled. The page slot index is `+0xB9 * +0xE9 + slot`. Past the door count (`+0x10A`) it is a trap: it resolves the slot through 0x00411080, sets `+0x13DB = 7` and `+0x13E8` = the trap id, then submits selection cleanup 0x00422600(4, id). It clears the FlashButton descriptor when that is category 4 with the same id. Otherwise it is a door: it walks the door list (world slots `+0x13C`/`+0x148`), skipping entries for which 0x004BACD0 returns 1. It sets `+0x13DB = 6` and `+0x13E8` = the door id, submits 0x00422600(3, id), and clears a category 3 descriptor with that id. Both paths call 0x004094C0 first and 0x0040ABC0(1, 0); in the trap path 0x0040ABC0 comes before 0x00422600. Their meanings are taken from the sibling room and spell callbacks, hence LIKELY.
