Thiscall on the room with (x, y, amount). For each slab from (x, y) (next via the slab's +4 word, wrapping to the room's first slab +0x2D) it takes the first object on the slab of kind 2, owned by the room's owner, with object type byte +0x12C equal to 3: a pile holding more than the remainder gives the remainder and stops; otherwise the whole pile is taken and the object removed. Each take lowers room +0x49 and the player's total (Player_ChangeGold with flag 1). The walk ends back at the start or when nothing remains; it then refreshes the room's fill display. Player_ChangeGold's negative branch calls it with each store's first slab. Read by decompiler.
