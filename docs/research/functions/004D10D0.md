It first calls 0x004D56E0 to register the behaviour list, then stores four function-and-context pairs through the setters 0x004D2770 to 0x004D27D0 (contexts at 0x006ED40C to 0x006ED418): the ungated object enumerator 0x004D1170 for Separation, the Obstacle-gated enumerator 0x004D12B0 for Repel_Obstacle, the crowd probe 0x004D15E0 for Follow_Path's seek, and the navigation-byte probe 0x004D16B0 (world +0x9F2) for Avoid_Walls. steering-behaviours.md lists the four installed functions as CONFIRMED from the binary. The callbacks' behaviour is built behind ISteeringWorld, but nothing mirrors this installer itself.
