Ordinary software hand sheets are published elsewhere, not by this icon routine. Called from 0x00403FB0 (0x00404D88) with the pointer position. It returns when +0x132E bit 0x01 is set or +0x2722 is non-zero. Over the GUI (+0x12B2) x moves left by 40*W/640. The icon index into [0x006CE958] + i*0x1B (names from table 0x0068F978) depends on mode: 3->7 Place_Room, 4->11 Sell, 6->6 Place_Door, 7->8 Place_Trap, 10->9 Query, 5->2 or 12 by special 0x7F/0x8C, and 8 draws the spell art through 0x0040D310. The icon goes at (x + 82*W/640, y + 10*H/480) with size 0x20x0x20. When +0x13E4 != 0, 0x00415650 draws its absolute value at (icon + 30, icon + 10): negative values are tinted 0xFF8080FF when money >= cost and 0xFF0000FF when not, positive values 0xFFFFFF80. No Go is index 5 at the same anchor. Mode 8 leaves the index at 13, so 0x0040D310 alone draws (the spell's own icon, No Go anchor moved by (-2, +2)) and no price is drawn. Mode 0 (Hand), with bit 0x08 set and the pointer off the GUI, calls 0x0040CFE0, which draws the held-item icons and sets the No Go anchor to icon 0 moved by (-2, +2); its index stays 13, so no I-* icon or price, and No Go then draws over the held icons when bit 0x02 is set and bit 0x04 clear. Over the GUI every mode that breaks out of the switch with an anchor (3, 4, 5, 6, 7, 8, 10) also sets bit 0x02 here (0x0040CDD9..0x0040CDE1), Query included.
