A thiscall on the creature with six stack arguments (RET 0x18): the action index, a cycle count, a pointer to a position and three more passed on to 0x00496700. The count plus one goes to +0x3AE, which the runner 0x00496AA0 counts down once per animation cycle, so the action plays its animation count + 1 times. Prison state 116 calls it with action 41 and a count of rand(3) + 2. LIKELY on the cycle reading, which rests on renderer flags not read.
