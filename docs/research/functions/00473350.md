A thiscall on the state object (+8 the creature, +0xC the world). Every tenth
state turn, or while latch +0xAC is set, it gets the prisoner's tile and its
first kind-2 thing. Only that object is tested: its nonzero +0x138 must equal
creature+0x3B9 and its type must be 49..51. Turning toward its position through
0x004B2AE0 sets the latch and returns while the turn is incomplete. Once
facing it, the prisoner adds a horizontal vector of length 0x1000 along its
heading, with zero Z, to the object's persistent velocity (0x00473475 calls
0x004B1F20), starts process 28 through 0x0049EF60, clears the latch and returns
before the action/roll branch. There is no clear-tile test here. The spin
handler is [004A1A60](004A1A60.md).

Otherwise, when 0x00496D00 reports no running action, it calls
CreatureDef_HasArt(9) on the definition (no draw), then random(100). With the
art and a roll under 10 it draws random(3), adds 2 and starts action 41 (0x29)
through 0x00496A30 at the creature's position; otherwise a roll under 20 sets
state 115 (0x73). It always returns 1. Ours collapses 114 to 116 into
PrisonerWanderSystem; the look-at and kick path is not modelled (ADR-0073,
ADR-0301), so this function is only partially mirrored.
