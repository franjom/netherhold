Called by the Speech Volume callback 0x00428F00 after it stores the volume. When the widget state +0x41 is 3, its flag (virtual +0x50) is clear and the interface handle +0x3E is zero, it asks 0x345 with handle 0 in the category at interface +0x4A (OPTIONS_SPEECH), stores the handle and sets the flag (virtual +0x4C); when the state leaves 3 it clears the flag and sends the stop command to the kept handle. Built in OptionsPagesController.BeginSliderDrag.
