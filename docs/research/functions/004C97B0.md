Called by 0x004C98B0 when the cached triangle for the point's cell carries the dead byte 0xFF. Computes the cell as the caller does, then tries the cells left (`cell - 1`, if the column is above 0), right (`cell + 1`, if below 3), above (`cell - 4`) and below (`cell + 4`) for a live triangle in that order, then every one of the sixteen entries in order, then the first live slot from 0, and returns -1 when none is live. Built as `NavMesh.RefreshLocateCell` (ADR-0486).
