Called by 0x004C98B0 when the cached triangle for the point's cell carries the dead byte 0xFF. Tries the cells left, right, above and below the entry's for a live triangle, then every other cache entry, then the first live slot from 0, and returns -1 when none is live. The replacement is whatever those hold, so the walk's start, and with it the first containing triangle it reaches at a vertex, depends on what was located before. Not modelled: ours (`NavMesh.Locate`) walks from one hint and falls back to a slot scan, then returns the lowest slot holding the point (ADR-0157).
