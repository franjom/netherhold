It takes the requested state id (and a second argument, called with 0 almost everywhere) and reads the current one from the state object's `+0x10`. The rule compares the group tag (`+0x16` of the 25-byte record, equality only) and indexes the category (`+0x17`) into the mask table at `0x00699688 + cat * 0x40`, testing the target's bytes in a fixed order (creature-state-table.md §2.2). travel-states.md §3 reads the rest: entering a category-2 walk saves the current id at `+0x40` and runs no hooks; otherwise differing categories run the leave hook, drop to state 1, then the enter hook; commit writes `+0x10`, stamps `+0x18` and zeroes `+0x1C` and `+0x44`, and it never writes `+0xDF`.
