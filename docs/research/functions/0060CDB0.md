Read whole; preserves selected volume and pitch through property setters, copies callback instance and request properties. Instance flag8 takes the head-relative/nonspatial branch; other branch computes spatial properties. Instance flag4 sets backend repeat count9999 through0x00615240. Timing branch includes a250ms offset, but does not establish a250ms fade contract.

Distance mapping (read 2026-11-11, hand-off and units traced 2026-11-13). In the spatial branch (instance flag 0x8 clear), after the start-offset step, it builds three floats at 0x0060CF5D and copies them to the voice block at +0x3C..+0x44, setting mask bit 0x200 of +0x14 (the only setter of that bit in the sound code):
- minimum: 2.0 (0x00673F2C), mixer units (2 per tile, see below).
- maximum: the float at +0x22 of the instance's current item (instance +0x8, the 42-byte SFX.map item, not the 20-byte group; see 0x006104F0), or, when instance flag 0x200 is set (a request range from 0x0060C960), the mixer ratio `[0x007A53B4] + 0x30` times instance `+0x4C`. A value of 2.0 or less becomes 2.1 (0x40066666; `FCOMP` at 0x0060CF33).
- third: the constant 0.5 (0x00673F34) from 0x0060CFE0: QMixer's `scale`, a rolloff multiplier on the distance past the minimum (see [qmixer-distance.md](../qmixer-distance.md); STRONGLY INFERRED).
Then it scales the instance position at instance +0x10 (three floats) in place by the same ratio through 0x00609130 and points block +0x34 at it, so the position and the distances share one unit: the ratio is 2 / 4096 per world unit (0x0060E4B0, set by SoundSystem_Init), that is 2 mixer units per tile. The head-relative branch (flag 0x8) builds no distance mapping, so its block keeps mask bit 0x200 clear and the item's +0x22 is never read for it.
Hand-off (STRONGLY INFERRED): the block is applied by 0x00617510, which tests mask bit 0x200 and calls backend vtable slot +0x70 with (result, voice handle, block +0x3C); the slot reaches 0x0061AE30 only when the QMixer backend is the one in use (a first backend, A3D by hypothesis, is tried first, see 0x00618040). Callers: instance start 0x00615840 (and the undefined code at 0x00616283), through the thin wrapper 0x006157B0 that clears the instance link on success. Every spatial voice that BindVoice accepts therefore carries the mapping.
Suspected DK2 defect: unfiled. The position scaling at 0x0060CF94 mutates the instance's stored position, so a second BindVoice on the same instance would scale it twice; no second call was found.
