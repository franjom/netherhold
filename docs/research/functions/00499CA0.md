Each branch requires current turn strictly greater than creature +0x3A5
plus threshold, then restamps +0x3A5. With a check each turn, intervals are
therefore threshold plus one turns, not threshold. Healing walks the owner's
creature chain and calls 0x004B2CE0 with positive 5 or 8. Anger uses the signed
runtime prayer amount at 0x006F28E8, divided toward zero, through 0x00478B80.
Gold uses the world random stream, 0x004BA420 and floating digits 0x0050FB70.
Both object branches randomize heading after successful creation.
The object/Tremor point is the tile centre immediately west of the occupant,
height zero for objects. Tremor calls 0x00510290, not an unidentified visual
effect; its duration uses runtime variable 19 at 0x006F2590.

All unlisted types have no periodic effect in this handler. Their passive
occupant counts are separate (0x004D8E60). Shipped-map reachability: Q375.
