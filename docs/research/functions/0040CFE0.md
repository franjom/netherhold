Called only from 0x0040CAE0's mode 0 case (0x0040CBB2), which runs it when interface +0x132E bit 0x08 is set and the pointer is off the GUI (+0x12B2 == 0); 0x0040AE80 clears bit 0x08 over a dig-taggable tile with nothing to pick up, so the icons hide there. It does nothing unless the player holds something: a pending-drop record (+0x142 + 0x36 i, count +0xEF8) with dword +0x0C zero, or slot +0x26C true. It then draws, through 0x0040D450 with a running index, first the pending records from the newest down (slot +0x278 false, +0x0C zero, the thing slot live in 0x006ED540), then the hand from its last slot down (slot +0x270 count, slot +0x274(i) the thing id), skipping a thing a pending record with +0x0C or +0x10 equal to 1 already names. A ninth thing stops the walk and draws interface art catalogue entry 70 (+0x12B6 + 0x762, gui\Creatures\more_creatures) at the anchor plus the table entry 8 (128, 32), size 0x20 x 0x20. The anchor is (x + 82*W/640, y + 10*H/480) as for the tool icons, and the table at 0x006CE910 (filled by 0x0040AA40) adds unscaled offsets. Last it writes the No Go anchor (x + 82*W/640 + table[0].x - 2, y + 10*H/480 + table[0].y + 2), so 0x0040CAE0 draws No Go over icon 0 when bit 0x02 is set and bit 0x04 clear. With an empty hand it writes no anchor.
