Arguments (triangle, vertex slot). Checks that the fan closes in three; returns 0 otherwise or on the hull. The given triangle takes the vertex's place from the far triangle's corner and adopts the two outer neighbours, whose back links are rewritten. Clears the two dead triangles' region ids. Pushes each dead triangle onto the list at 0x006A11D4 (link in +6, byte +0xC = 0xFF, live count 0x006ECA30 decremented); the allocator 0x004CA820 pops that list first, so the slots are reused last in, first out. Recomputes the kept triangle's width classes (0x004C8F50), and pushes the point onto the list at 0x006A11D8 (link in +0, +2 = 0x8000, count 0x006ECA38 decremented), whose pop is unread. Returns 1.
