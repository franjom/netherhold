Free count at +18000 (0x4650); an existing entry of the kind at the tile returns 0 with its id. Raising kind 1 first removes (0x00507EF0) the tile's kind-6 and kind-16 entries, each when its entry is allocated and carries its id; raising 6 or 16 fails when a kind-1 entry is at the tile. The new entry takes the free-list head (+0x4654), allocated = 1, twelve worker slots cleared; its id is that slot's own +0x21, preset per slot, so an id is a slot index reused through the free list. The word +0x4652 (the dumper's NextUniqueId) is incremented and wrapped (above 499 to 1) but never stored in the entry. 27 call sites all push an immediate kind; kind 11 arrives through the marking routine's shared call (0x00512EBC), where three arms set the kind before one CALL.
