Read whole. Stores the point at `+0x48/+0x4C`, then the top-left is `point + (+0x40, +0x44)` and the bottom-right adds the image size `+0x14/+0x18`; the rectangle is clipped against `+0x30` (0x005B6FD0) and an empty clip hides the cursor. With 0x005DC120's offset this is `topLeft = pointer - scaledHotspot`. Called by 0x005DBF80, which skips the move when the point and dirty flag are unchanged; 0x005DBF80's callers are 0x005DB8E0 (timed redraw), 0x005DC120 and 0x005DC830 (from 0x005DBB10, which reads the point from a mouse source through its vtable; that source is unread).
