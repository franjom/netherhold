The caller supplies DC in EAX and the bit position in EDI; the block buffer is cleared and
DC times the first step is stored first. An invalid prefix (under 0x20) ends the block without
advancing. The escape arm consumes run and level, with one more byte for the 0x00 and 0x80
level forms, and advances one slot in all cases. Both 0x00666480 and 0x00668810 call it;
its engine twin is 0x00659608. Our code refuses invalid prefixes and runs past slot 0, which
the binary does not check.

Suspected DK2 defect: DK2-037. The run counter is one byte (BL) and never bounded, as in the engine copy 0x00659608: a run past slot 1 wraps it and the zigzag lookup reads past its table. Unreachable on shipped data.
