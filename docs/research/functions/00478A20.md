fastcall; the argument is the creature's state object (creature +0x24E: its +0x10 is the state id at creature +0x25E, +0xDF the resume state at +0x32D, +0x08 the creature). State object +0x3C 1 returns 26, 2 returns 25. A creature whose definition (+0x370) flag byte +0x686 bit 0 is clear (a non-worker) returns the dword at 0x006996C4 + 0x40 x category, the category being the state table byte 0x006DA8C7 + 0x19 x state, with the resume state's category when that is 2. A worker returns 5 when creature +0x3D1 (dword) is nonzero or state object +0x98 (creature +0x2E6) is 6; otherwise 6, or 4 when the category (resume's for 2) is 0x16. State object +0x98 is the imp's last task kind: each task handler writes it as it takes a task (0x0046AEA0 writes 6 for a reinforce, 0x10 for a repair) and only state 10 (0x00464010) and state 11 zero it, so it stays 6 through the walk, the work and any fight until the imp next chooses. A worker therefore gets 5 with no task (+0x3D1 nonzero) or a last task of reinforce, never after a dig, mine, claim or repair. The Level 17 capture fits (kind 1 in 13/14, 2 in 25-29, 3 in 15-18, 6 in 21/22 over ticks 1-600), and the Level 11A capture slaps its keepers' imps from states 6, 10, 12, 22, 87 and 199 with kind 6 or +0x3D1 set, 53 of 6,429 eligible imp-ticks over 1-1,400 (computer-keeper-management.md §8).
