When `player+0xB53` is set and due it sends message 0x2E, then walks the player's creature chain: a payable, non-exempt creature with `GetPaid` (`+0x3E2`) clear accrues its wage (`0x0048B6B0`), has its failed attempts `+0x474` zeroed and tries to collect (`0x00472320`); one with `GetPaid` set only has it consumed, so a treat prepays exactly one payday. It then sets `+0xB53` to now plus `PayDayFrequencySeconds` (global `0x006F25D1`, which it is the reader of) times ticks per second, and `+0xB4F` to now. Read from the binary; no capture pins the timing, so LIKELY. PaydaySystem mirrors it.
