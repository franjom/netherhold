Read 2026-10-01 by disassembly, `0x00454040`–`0x004540bf` (`RET 4`; ECX the tile, the argument the imp's player id).

- The tile's owner (`+0x8` & 0xFFF) equal to the argument → 0.
- Flags = terrain record `+0x17B` of the tile's terrain (`+0xA`).
- **Ownable (0x4) and Attackable (0x20) and not Solid (0x1):** not Room (0x10) → 0; else the room (`+0x2` & 0xFFF into `0x006EE540`): type `+0x18` = 5 (Dungeon Heart) returns its `+0x9A` bit 0, any other type returns 1.
- **Otherwise:** not Room → 0; else return the room's `+0x9A` bit 0.

`+0x9A` bit 0 is the ruin (`0x004E9130`, Q263). So an ordinary rival room converts at once, a heart once ruined, and a room whose terrain is not Attackable — in the shipped data the five gates: Hero Gate Final, Tile, 2x2, 3x1 and the Mercenary Gate — only once ruined, which trigger action 32 COLLAPSE_HERO_GATE does. In Level 1's capture no imp targets the heroes' 2x2 gate in 2,044 turns. Built as the Attackable term of `TileWorkRules`' ConvertRoom (ADR-0299); the ruined-gate case is not, since action 32 is not built.
