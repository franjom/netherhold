Read whole by decompilation. The creature action starter passes an animation object embedded at creature+0x44, a compact resource, scalar 4096, the requested art slot and an immediate-install flag. Immediate installation resets normalized phase (+0x94) and advance rate (+0x98) to zero, installs the resource at +0x28, and calls 0x004B41E0. Resource flag 8 selects an initial start segment. The general routine also supports deferred replacement and other resource types; their behavior is outside the Tremor timing conclusion. Type 0 bypasses the type-6 rate calculation, leaving the rate zero.
