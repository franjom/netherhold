Arguments (t, k). Returns 0 if there is no neighbour across edge k, if the two +0xC bytes differ, or if bit k of t's +0xD or bit j of u's +0xD (j the back slot) is clear. Bits 0-2 are set by the reset (+0xD = 7 on both canvas triangles), by every split and clone on the new edges, and are moved but never cleared by the flip; a search of the mesh functions found no other writer of +0xD, so that test never refusing is STRONGLY INFERRED. Then, with a = t.v[k], b = t.v[next k], c = t.v[prev k] and d = u.v[prev j], the shared edge's ends a and b must lie strictly on opposite sides of the line through the apexes c and d (two 64-bit orientation tests, the same pair 0x004C9FC0 makes with the operands in the other order), and the squared length of the apex-to-apex diagonal must be strictly less than the shared edge's. Constraint bits (3-5) are not tested here; the flip 0x004C9FC0 tests them. Called only by 0x004CC650, on edges 0, 1, 2 of every popped triangle, which then calls the flip without reading its result.
