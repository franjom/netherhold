It is the only reader of the behaviour pointer table, matching each singleton's name string and pushing an 8-byte {weight, behaviour} pair onto the list at 0x006ECAE0 (base, top 0x006ECAE4, limit 0x006ECAE8). The four are avoid_walls 0x9999 (0.6), repel_obstacle 0x6666 (0.4), follow_path 0x5999 (0.35) and separation 0x2147 (0.13); avoid_obstacle is never registered although it is implemented. Called from the steering initialiser 0x004D10D0; the list is consumed by 0x004D4760.
