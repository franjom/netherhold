Read 2026-10-01 from the decompile. Called from two thunks, `0x005129A0` (last argument 1) and `0x005129E0` (0), which unpack a rectangle from a command record and pass the player `0x006EE540[+0x10]`. Clamps the rectangle to the map (`+0x1CC`, `+0x1D0`). With 0, every taggable tile (`+0x17B` bit 3) in it gets `0x00507EF0(1 or 2, tile)`, 2 when the terrain has gold (`+0x185`). With 1, it walks the rectangle in an outward spiral (direction table `0x006BC350`/`0x006BC354`) and calls `TaskPool_MarkTile` on each tile inside. A player gesture, not dig completion.
