Argument (t). Masks the word with 0xFFC0 and ORs the three classes into bits 0..5: the edge v2 to v0 in bits 0-1, v1 to v2 in bits 2-3, v0 to v1 in bits 4-5; 0x004CA500 and 0x004C9400 read the region id as `>> 6`. Called after every split (0x004CA500, 0x004CA820), by the reset for its two triangles and by the flip. Touches no vertex, neighbour or byte, so the geometry the game routes on is unaffected. Ours does not model the classes; whether anything reads the low six bits has not been scanned (0x004CCB30 writes them, which suggests a reader), so "unused" is not claimed.
