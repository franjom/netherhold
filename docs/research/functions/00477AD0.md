The one routine both eat states call: the hatchery's `0x00463760` passes 1 and the prison's `0x00473750` passes the level-scaled `HungerFill` (eating.md §7). The caller stores whether the returned need is nonzero in a byte on the state object, and the eating states branch on that byte to go round again. trigger-walkers.md lists it as the only site of trigger event 54, hunger sated. `EatingRules.Swallow` does the same floored subtract; ours returns the health gained rather than the remaining need and reads `StillOwesFood` instead.
