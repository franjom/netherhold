Read whole 2026-10-26 by decompile. Fastcall on the state object (creature +0x24E). Returns 0 unless creature +0x3CB (held in a prison) is 0 and the definition's TimeSleep (+0x5D6) is non-zero. With no bed (+0x3B7 == 0) it calls the lair attempt 0x0046F390 and returns 0, whatever +0x58 holds. With a bed, it routes only when the sleep latch +0x58 is non-zero and the bed object's +0x138 names a room: the room helper 0x00471A70 with resume 81 (call site 0x0046F4B0, travel-state-call-sites.md) returns 1; a failed route posts message 0x2B to the owner and returns 0.

Callers: the job switch 0x00478800 (0x0047888B), the needs routine's tired attempt (0x00477F0C, every 4 turns) and its wound branch (0x00478023). Nothing on the wound branch writes +0x58, so a wound alone does not send a bedded creature to bed; a bedless wounded one gets a bed through 0x0046F390 and state 80's wound test (0x0046F785) and sleeps untired (creature-needs-routine.md section 3). Ours: CreatureSleepSystem.SetOff with LairRules.WantsToSleep as the latch (ADR-0543).
