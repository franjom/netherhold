Read by disassembly (Ghidra has no function here; 0x00481CF0–0x00481D40). Returns 1 while `0x00496D00` says an action is current. Else `now = 0x00517490(world)`; while `[state+0x7E] + 0x32 > now` (unsigned `JBE`), if the creature has action 43 (`0x004966C0(0x2B)`) it starts it (`0x00496700(0x2B, 0, 0, 0)`) and returns 1; otherwise returns 0, which is idle. The word `+0x7E` of the state record (creature+0x24E) is creature+0x2CC, which `0x004E8DA0` stamps with now just before `KickToState(250)`, so the stand is 50 turns from getting up, or until a fight. Ours: `DropLandingRules.Stands` on `StateDeadlineTick`, stamped by `AfterGettingUp` (ADR-0226, ADR-0344); action 43 itself is not played.
