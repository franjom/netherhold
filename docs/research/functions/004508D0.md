Thiscall on the map (world `+0x9DA`), four stack arguments (RET 0x10): x, y, a pointer to the delta and the worker's player. The map holds its width at `+0x0C` and its tile array at `+0x14`; a tile is 16 bytes, so the tile is the array base plus (y times width plus x) times 16 (runtime-map.md, CONFIRMED by run 15). With a tile it passes the delta pointer and the player to Tile_ApplyWork (0x00452F60) and returns its word; with none it returns 0, which is the zero computer-keeper-messages.md sees the terrain-work path test. Every tile-work handler reaches the applier through it (imp-claim-path.md §7), and so does action 11, the room attack. Our code indexes tiles directly; TileWorkRules.Apply is the applier.
