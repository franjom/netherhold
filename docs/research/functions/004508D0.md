The map sits at world `+0x9DA` (seen at the caller `0x0049713D`); it holds its width at `+0x0C` and its tile array at `+0x14`, and a tile is 16 bytes, so the tile is the array base plus (y times width plus x) times 16 (runtime-map.md). Every work handler reaches the applier `0x00452F60` through it (imp-claim-path.md §7). CONFIRMED by run 15, where tiles read at those addresses came back with plausible terrains and healths. computer-keeper-messages.md has the terrain-work path test its result for zero and calls that result's meaning UNKNOWN, likely an out-of-map null. Our code indexes tiles directly; dk2watch.py uses this layout, nothing in src/ mirrors the function.
