The inspected first loop covers an eleven-by-eleven neighbourhood, clamps computed height to 15 and notifies changed tiles. The rest of this routine is not classified by this reading.

Primary source: DKII.EXE decompilation inspected during the wall-support trace.

Each nibble is min(15, Math_Isqrt(d2 << 4)) with d2 the squared distance from the tile's corner point to the nearest tile that world slot +0x210 (0x005091C0) accepts (terrain Solid, or tile bit 0x4000 pillar); both passes use the same measure, so they agree. Callers (x, y, mode): Tile_SetTerrain 0x0045001B (mode 0), Room_PlacePillars (0), Room_CloseRemoveRectangle (0), Room_RefreshPillarMovementFlags (variable), Defeat_LocalPlayerCollapse (1). Digging, claiming a room or placing pillars therefore re-derives the roof height around the change.
