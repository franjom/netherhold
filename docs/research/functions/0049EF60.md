A thiscall helper taking one state argument (RET 4): `MOV [ECX+0x13E],0` then `MOV [ECX+0x13A],arg`. No test of the current state, so setting the state an object is already in restarts it (age 0; the handler's entry block runs again when the age reaches 1). Create Object uses it to send type-1 gold into falling state 1; game action 26 (0x005149BB) sends a struck Training Dummy (type 14) into state 18 (0x004A13F0).
