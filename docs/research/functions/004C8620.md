It takes the record's type at +0xE, subtracts 10 and sends anything above 0x28 to the default at 0x004C8A3E. Otherwise it reads an index byte from 0x004C8A98 and jumps through the 14-pointer table at 0x004C8A60, with index 0x0D as the default. The table gives 10 and 11 to pointers 0 and 1, 24..28 to 2..6, 31 to 7, 34 to 8, 37 to 9, 38 to 10 and 42 to 11 (all read 2026-10-01). That matches PlayerOwnsAction's set as far as it was read; 50's index was not read. Arm 28 is 0x004C8851 and passes body bytes 0 and 1 to 0x004DC8F0 (portal-creature-action.md). Arm 37 is 0x004C892D: when body byte 0 is zero it clears the player's +0x76 bit 10 (PortalsOpen, named by the dumper at 0x004BDCEA), otherwise it sets the bit, and either way it returns 1. Only the dispatch tables and arm 37 were read here; the other arms are described in trigger-dispatch-tables.md where read, and their bodies are not part of this record.

Arm 24 is `0x004C8688` (index 2; read 2026-10-04, Q227). It posts `Message_Post(0x15, TagId, SpeechId, 0, allocate)`, where allocate is `low byte of the second dword == 0` (`NEG DL; SBB; INC`); the other three bytes are unread. Unless `Message_Post` suppresses or deduplicates the post, 0 plays the speech and posts a record, and non-zero only plays the speech. Arm 50 calls world slot `+0x370` with the second dword, which stores world `+0x72B8`.

The view arms (read 2026-10-17, camera-paths.md): each acts only when the tree's player is the local one (world slot +0x264) and queues a game action through 0x0050E5C0; the view's handler table 0x0066CE30 holds a handler for each id, and the delivery from 0x0050E5C0 to that table is unread (LIKELY). Arm 26 (pointer 4, 0x004C86CF) queues action 4 with the action point's centre packed x | y << 16 (camera glide, 0x00442650). Arm 31 (pointer 7, 0x004C886E) queues 0x73 with PathId (bit 31 set when byte 2 is non-zero) and the centre ((StartX + EndX) / 2, (StartY + EndY) / 2) (0x00442540). Arm 38 (pointer 10, 0x004C8955) queues 0x74 with byte 0 == 1 (the letterbox, 0x004426F0) and calls the interface [[world+4]+0xC] slot +0x38 for 1, +0x34 otherwise. TriggerExecutor runs 10, 11, 28 and 37 (ADR-0314) and 24, 26, 31 and 38 as view requests (ADR-0496); action 24's retained message is built (ADR-0535); unimplemented arms are reported partial.
