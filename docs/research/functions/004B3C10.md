Read whole by decompilation; entry and completion instructions checked. The normalized phase +0x94 advances by rate +0x98, or by +0xA4 during the alternate-rate mode. A threshold of 4096 selects segment transitions. Resource flag 8 enables a start segment and flag 16 an end segment; their lengths are resource bytes +8/+9. Transitions compute each segment duration with fixed-point frames/FPS division, then divide overshoot by nextDuration/previousDuration, preserving every intermediate truncation. Start-to-main carry at or below 4096 returns immediately, including equality. If that carry exceeds 4096 and no end segment exists, it clamps to 4096 and returns without marking completion; the next advance marks completion and the following advance zeroes the rate. A looping main segment wraps; a nonlooping terminal segment marks object+0xAD bit 1. On the following update the completed branch zeroes +0x98. The routine also handles queued resource replacement and alternate-rate playback; only ordinary immediate nonlooping playback supplies the Tremor duration calculation.

The normalized-phase threshold also raises RenderInfo +0x4E bit0x20, which is thing+0x92 bit0x20. It remains pending until the Heart presentation consumes it; neither 0x004B3AD0 nor 0x004B3B40 clears it. See heart-mana-effects.md section 4 for the original Heart pulse request.
