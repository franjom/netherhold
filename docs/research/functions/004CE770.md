Sorts the rectangle, returns on an empty or -1 one, and widens to the whole map unless the rectangle keeps one tile clear of every edge (x0 >= 1, y0 >= 1, x1 + 1 < width at 0x006EC9C8, y1 + 1 < height at 0x006EC9CC). The level build's caller 0x004CEF20 passes (0, 0, 0x100, 0x100), so it takes the whole-map path by that test. The first call ever also resets the canvas (0x004C8D10 with -256..1280 tiles).

Whole map: reset, base rectangle of byte 0 (0x004CCCB0), then the scanner 0x004CE570 with byte-0 rectangles skipped, a coarsening pass 0x004CC650 after each (navigation-mesh-and-search.md §2.1).

Partial:
- side cuts 0x004CDFE0/0x004CDF20 and constraint marks 0x004CE380 on all four sides;
- interior emptied by 0x004CE0C0 unless 1x1;
- one rectangle when the bytes are uniform (1x1, or under 4x4 and uniform), else the scanner from the rectangle's top (skyline 0x006E7EE8), with byte-0 rectangles inserted;
- coarsen;
- 0x004CE410 queues the four sides' points and clears their constraint bits, and each queued point whose fan has one byte all round is reduced (0x004CAF40) and removed (0x004CB170 for degree 4, 0x004CB8C0 for 3).

Ends by finding a hull edge (0x004C9710) and rewalking the hull ring into 0x006E86F0. Writes nav.log lines when the dead global 0x006EC9E8 is set.

Ours builds once and edits changed tiles through `NavMesh.Retriangulate` (ADR-0461, ADR-0486). A refresh batches changes in tile order rather than native write order. The Level 1 execution327 controlled native fresh build and two partial edits establish bounded mesh/route history dependence and native/modern agreement from the same starting mesh and ordered bytes; see navigation-partial-rebuild.md §6. They do not establish whole-campaign update equivalence or loss causation.
