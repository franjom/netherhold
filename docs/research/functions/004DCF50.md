On success it posts message 0x0D, starts action 0x31 with state 0xC1 (the joining state 193) and sets the body fields that 0x004DC9A0 also sets. It then sets the +0xFCE flag to 1 and returns 1 whether or not the create succeeded. When no type qualifies it returns 0. Read whole 2026-10-01 from the decompile. What 0x004DD130 tests is unread, and nothing in our simulation runs a non-campaign mode, so this stays READ.
