Returns 1 (stays) while signed floor word +0x26 is below Z dword +0x22.
Otherwise it calls 0x0048FD70 with 0x1000 (normal scale), clears +0x3CD,
and branches on definition flags +0x686: bit 14 enters 1 then 235;
bit 0 (worker) makes world slot +0x38C effect 0x1D at the creature's position
with its +0x28 tag and heading 0, then returns state 76's landing handler
0x0046EAB0's result; anything else returns 0. There is no duration counter.
Shipped Effects.kwd names effect 29 Imp Birth Trail (element 18, Sparkle-02g).
Neither creation process makes a worker effect (0x004AD7A0 for shot 2,
0x004AFE50 for upgraded shot 60) and the cast 0x004BBD30 plays only a sound, so
this landing effect is a Create Imp's only visual, for bought and free Imps
alike (the free cast, 0x004BB2A0, reaches the same 214). Unlike
Portal_CreateArrival, nothing on the way tests the effects-detail setting
0x00759AEC: slot +0x38C (0x00509580) forwards through +0x388 (0x0050E490) to
View_CreateVisibleEffect 0x00440420, whose gates are its component +0x2655,
bounds, solidity, exploration and the camera (definition flag 0x8000 skips the camera); ours requests it Gated, the same gate.
