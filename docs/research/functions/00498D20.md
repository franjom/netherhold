Installed by the action-table filler at `0x00495897` into `0x006E4538`, which is record 32 of the 29-byte table at `0x006E4198` (0x3A0 / 29 = 32). Action 32 is started from exactly one place, `0x0047053E`, in the handler of creature state 64 (manufacturing, `0x00470470`), which then moves the creature to state 65. The body (fastcall, the creature in ECX, no stack arguments) first applies the combat-cadence Gate A: nothing happens until the game turn exceeds `creature+0x3A5 - 1 + def+0x5CA`. Past it, and only when the creature's resolved state category is 5 (Workshop), it asks the world for the tile under the creature's position (`+0x2F7`, `+0x2FB`), walks that tile's thing list, takes the first object (thing kind 2) whose definition id `+0x12C` is 15 (Anvil in Objects.kwd), and calls the effect service at `[0x0075B468]` slot +0x20 with the anvil's handle `+0x2E`, a value from its definition `+0x10E`, the literal 0x112 and its position `+0x1A`, storing the returned handle back in `+0x2E`. It always returns `creature+0xF1` bit 1 inverted. So it is the hammering cue of manufacture, not a rate: no manufacture points are added here. The call is the sound manager's positional request (vtable slot +0x20 of 0x0075B468, 2026-11-02): the anvil's sound 0x112, three samples in OBJECT_FORGE. LIKELY for the rest of the handler.
