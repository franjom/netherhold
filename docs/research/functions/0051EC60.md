Calls 0x0044FC40 at 0x0051ED28, 0x0051ED81 and 0x0051EDDF. For non-room terrain the owner argument is the record player's id; room-flag paths pass [0x006F2548] or a fixed byte. Because Tile_SetTerrain substitutes the neutral player for non-ownable terrain, every unclaimed tile ends with the neutral player as its owner (Q514). Ours copies the authored owner (WorldState.FromMap), leaving 3,629 shipped non-ownable tiles with owner 1 or 3. All three Tile_SetTerrain calls pass argument 5 = 1, so each map tile posts bridge command 3, which the closed gate drops during the load. 0x0051E0A0 installs this callback only when [session+0x7239] bit 0x4 is set (otherwise 0x0051EB50/0x0051EE60); which path a new-level load takes is unchecked.
