Read whole. A null surface hides the cursor (0x005DC7D0). Otherwise it grows the save-under size to the source rectangle, copies the rectangle into the cursor surface (0x005B57F0), then stores `+0x40 = -hotspot.x`, `+0x44 = -hotspot.y` and sets the dirty flag `+0x2C`. Reached from the Hand cursor publish 0x0040ACD0 through 0x005B2BD0 -> 0x005BB2A0 -> 0x005DBAC0 (which takes the cursor lock around it). The hotspot argument is the loader's scaled value (0x0040C710: x * screenWidth / 640, y * screenHeight / 480, truncated).
