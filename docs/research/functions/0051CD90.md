The Variables dispatcher 0x0051AA90 installs it as the handler for 180 record kinds. It reads the id from record +0x10 and the value from +0x14, subtracts 3, and ids above 242 go to the shared no-op at 0x0051D736. Each cached id has its own stub: a store of AL, AX or EAX into the id's global, then a return of 1. Id 74 is table entry 71 (at 0x0051D85C), stub 0x0051CFE0, a dword store to 0x006F28B6. That stub is the only writer of 0x006F28B6 in any block (ScanAll, 3 hits: this store and the two readers 0x004643C7 and 0x004890D7). GlobalVariables.kwd carries no id 74. All 66 shipped level Variables.kld files carry it at 340, including level1 and level2 (dk2tools kwd varsweep and kwd vars). The global sits beyond .data's initialised bytes, so it is 0 until a level loads and 340 during every shipped level. The dispatcher and stub were read instruction by instruction, hence CONFIRMED.
