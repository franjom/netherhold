A thiscall on the runtime record, two stack arguments: the loaded resource handle and a pointer to the file ArtResource at its flags field (name excluded). It stores the handle at +0xF, then switches on the file's type byte (16 bytes past the flags) and per type copies the value fields to +0 and +4 and a byte to +8, writes the type at +0xA and the flags dword at +0xB. The creature loader 0x00492320 calls it for every present art slot, which is how a flag bit in Creatures.kwd becomes the bit CreatureDef_HasArt (0x00494A00) tests. Every path ends by ORing (type byte at +0xA != 0) into the flags dword, so runtime bit 0 is the file bit OR a type of 1..8; the loader gates the call on a nonzero file type byte and a successful load. All type arms have now been read; the type-6 field mapping is recorded below.

Read whole by decompilation, with type-6 instructions 0x00504E29-0x00504E64 checked.
