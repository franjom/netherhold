- The gate `(turn + room+4) % (TicksPerSecond * 5) == 0` covers only the first walk, along the slab chain from FirstSlab (+0x2D/+0x2E) through each tile's next link: a tile with flag word bit 0x1000 and state bits (+0x0B & 0x1E) of 0x11 or less is advanced by 0x00452B70; state 0x10 sets room+0x49 to 1, and state 0x08 posts bridge command 3.

- 0x004C5DB0 calls Room_RemoveTile (0x004ED440, which reaches Room_Rebuild's draws) and, for a non-zero room type, Player_ChangeGold with the sale value: DK2 therefore appears to refund a burnt bridge tile. Not confirmed against a capture.
