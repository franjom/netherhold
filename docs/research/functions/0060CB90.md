Uses signed item bytes+0x0E/+0x0F and swaps reversed endpoints. Parameter interpolation gates are item+0x18/+0x1C bit2 and instance+0x45/+0x46, /100. Otherwise min+rotr(next sound LCG,13)%(max-min); no draw for equal endpoints. Missing item returns0. This returns an offset, not a playback ratio.
