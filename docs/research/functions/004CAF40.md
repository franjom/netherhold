address: 0x004CAF40
name: NavMesh_ReduceVertexDegree
role: Flips edges around a vertex until its degree is 3 or 4, returning that degree (or -1 on the hull), so the vertex can be removed.
confidence: LIKELY
status: READ
evidence: docs/research/navigation-partial-rebuild.md#1-what-the-binary-does

In/out arguments (triangle, vertex slot). Counts the fan by walking neighbours; 3 returns at once. Otherwise walks the fan trying 0x004C9FC0 on the edge leaving the vertex at each triangle (the flip refuses constraint edges and non-convex quads); a refused flip advances, a successful one stays. On closing the fan it writes back the current triangle and slot. A count of 3 returns 3, an open fan -1, and 4 returns 4 when a recount agrees. Otherwise it logs "l0 %02ld n %02ld l1 %02ld" to a local buffer and returns the count if it is below 5, or loops again if it is 5 or more.
