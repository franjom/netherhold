Callback (record, world); not a Ghidra function. Registered by 0x0051E0A0 (0x0051E20F) and 0x00541AA0 (0x00541C8A), both at handler index 5. With +0xA3C7 clear and the count +0x160C below the capacity +0x1608, it moves up every entry from the end whose id (+0x75) is not below the record's (intermediate +0x166, file 0xEE), loads through 0x004F7CE0, adds the entry's +0x36 to world +0x1610 and counts it; a record past capacity is dropped. With +0xA3C7 set it calls world slot +0x110 (0x0050DD60) with the id, then the loader; that slot searches the sorted table downward from min(id - 1, count - 1) and returns the matching entry or 0, so the record reloads an existing entry. What +0x36 holds is not read.
