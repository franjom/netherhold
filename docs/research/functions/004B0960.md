For each tile it asks the per-player task pool (up to 500 entries keyed by coordinate, located at world +0x84 via playerId * 4389) through the lookup 0x00508290. Entries are created by 0x00512D20, kind 1 or 2 by whether the terrain carries gold, and the count includes both, so one tag bit per player per tile is the same quantity. Type 62 compares it against Value with byte 00; type 69 compares it with a literal >= against the taggable-tile count of 0x004B0A00. The pool layout was found through this function and sampled live (CONFIRMED in player-task-pool.md); the counter itself is a binary read, hence LIKELY. Ours models the tagged set as TileState.IsTaggedBy.
