Clears CurrentRoomToBuild and calls the chooser 0x004F93B0, which returns at once while a request is set. It copies NextRoomToBuild to CurrentRoomToBuild, clears the set bit only for 3 and otherwise writes 3 to NextRoomToBuild. Portal requests search neutral portals; others search a neutral room by the request byte, bit 7 included. After the cost test (+0x43F price x DefaultRoomSize against +0x7E), a request with bit 7 draws a room of its type (0x004C6460) and calls 0x004FBE00; with neither it clears bit 7. Task 1 starts only while Task is 0, so a successful expansion's task 2 stands.
