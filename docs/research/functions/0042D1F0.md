Hit kinds 2/3 creature (class 0), 4 object (class 2), 5 door (class 4), 6 dead body (class 6), 7 trap (class 3) require live tags and matching class, then call the thing's vtable +0x4C status formatter. Objects require nonzero definition name. Falls back to room, then terrain: a tile with byte +0xB bit 0 set reads 2481 instead of the terrain producer 0x00455450. Unexplored selects fog status. Shots have no hit kind.

Implemented scope: creature, dead body, object, door, trap, room and terrain dispatch. The dead-body arm (kind 6) and the doors' and traps' other-keeper arms are built but unreachable through the Hand pick (0x005992B0; Q634). The tile +0xB bit 0 arm is unbuilt (its writer is unread).
