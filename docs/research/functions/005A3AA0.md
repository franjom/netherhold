Decompiled 2026-10-02 and 2026-10-16; the effect pushes were read in the disassembly 0x005A3D40-0x005A4290. Called from Thing_DrawRenderInfo at 0x0059B9FF and 0x0059BA83, one site after each of its art-type 5 and 6 draws (record 0x0059B880), so it runs once per draw of a thing, not per game turn. Each control point id is bucketed by thousands (1000s -> 1, 2000s -> 2, ... 6000s -> 5; id 0x2711 = 10001 -> 9).

Arms that create effects, each through component slot +0xBC then slot +0x94 at the point's position:
- bucket 3 (2000-2999), thing +0x91 bit 0x20, and DAT_00759AEC > 3: effect 0x106 = 262, firey head effect.
- bucket 5 (6000-6999), thing +0x91 bit 0x80: effect 0x124 = 292, Horney persistent fire step (the points at floor height when the tile's terrain def +0x17B bit 0x80 is clear).
- id 10001, thing +0x92 bit 0x4: effect 0x101 = 257, Gem dust sparkles, at every point 10001, on every draw (push at 0x005A426B, call 0x005A4272).
+0x92 bit 0 with bucket 4 drives three calls to 0x005A1340; that bit is the one the torture leave clears on an Electric Chair and the chair action at 0x004995B4 sets.

+0x92 bit 0x4 is set by trigger action 20 (TriggerCreature_DispatchAction 0x0049AC80, arm 0x14), which also gives the creature a Portal Gem (object 28). Level 1 does this to the Lord of the Land on creation; LOL-Walk.kmf and LOL-Run.kmf carry a control point 10001. Live check 2026-10-17 (Level 1, map explored at tick 100, dump at tick 400): nine instances of effect 257, untied (+0x133 = 0), at (16.7-16.8, 10.5) with the Lord at tile (16, 10), and no other effect near him. That is the sparkle trail the owner saw; the Portal Gem's own idle effect 297 (state 50, 0x004A3C30) is not created while it is carried.
