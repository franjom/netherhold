Thiscall on the room, one argument, the object. It unlinks the object through its +0x124/+0x126 links (updating the list head +0x0C when the object was first) and zeroes both links and +0x138. If the room's UsedCapacity (+0x6B) is at least the object definition's (+0x12D) byte +0x114, it subtracts that byte from +0x6B and +0x6F. For an object of type 9 (Chicken, +0x12C), it then calls 0x004BFFD0, which is not read. This is the inverse of 0x004E5FF0. Read by decompile only, hence LIKELY.
