Terrain-35 reading (decompile 2026-11-05): for a tile with no room (word +2 & 0xFFF zero) whose terrain lacks ConstructionTypeWater (0x1000) and is not Solid, with no door, bit k of +0xC is set when neighbour k (table 0x006BC370) is off the map (0x00450626) or has another terrain definition, and nothing else sets it, so a terrain-35 tile reads zero only when all eight neighbours are on the map and terrain 35. Tile_SetTerrain calls it for the 3x3 around the tile at 0x00450293 (radius 1) when its argument 5 is non-zero, and the map loader passes 1, so the masks are final at the end of the map load. A tile with a room word goes to Room_TileCode and its byte is not written here. The Hero Lair sweep of 0x0050B5B0 tests the byte for zero; HeroLairRules computes the same condition from the terrain.
