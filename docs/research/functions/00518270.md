Switches on the record's type byte. Arms read 2026-10-04 (Q229):

- **Type 1 (flag).**
  - With flag id `0x80` it compares world slot `+0x340` (`0x00509650`, `LevelScore`) with the Value dword directly; there is no literal-bit test.
  - Otherwise it compares the flag byte at `+0x3F70 + id` with the Value, or, when byte 02 bit 0 is clear, with the flag named by byte 03.
- **Type 2 (timer).**
  - Timer id `0x10` compares slot `+0x34C` (`LevelTimeLimit`).
  - Otherwise an unstarted timer (`+0x3FF0 + 4 * id` zero) answers false. A started one is compared with the timer named by byte 03, or, in literal mode, the game turn is compared with its start plus the Value.
- **Type 34** compares the game turn.
- **Type 43** answers true.
- **Types 35, 44, 45 and 64** count things on the world's lists.
- **Type 67** reads `0x00561AF0`.
- Unknown types log "Unhandled Trigger When" and answer false.

TriggerConditionEvaluator mirrors types 1, 2 and 34; id 128 compares the score with Value and an indirect 128 is declined (ADR-0374).
