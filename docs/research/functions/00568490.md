Plays the queued speech event through sound manager slot0x24 and applies temporary effect/music ducking.

Around the request the throttle mode is set to 0 (0x005670D0 at 0x00568509) and restored (0x005670F0 at 0x0056853A); the request is slot +0x24 at 0x00568531 with |event|. Mode 0 lifts only the id >= 0x400 exemption, so a speech id below 0x400 is gated like any event: one that equals a listed id (sound-effects.md §4) is spaced or dropped on slow and heavy frames.
