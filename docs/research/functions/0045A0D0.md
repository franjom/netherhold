State 196 in the state table (creature-state-table.md, "leaving Dungeon"). It does these in order:
1. fires creature event 0x3F and player event 0x3D;
2. calls the entrance sacking update 0x004DC7E0 with the creature's type;
3. plays sound 0xDF;
4. posts message 0x14 unless the type byte is 0x2D;
5. makes the definition's effect +0x423 at the creature if one is set;
6. empties the purse with Purse_Spend 0x0048AF50(GoldHeld);
7. clears +0x3E6 bit 5 and destroys the creature (vtable +0x20).

Because the purse is emptied before destruction, the gold spill in the death bookkeeping has nothing to drop. A creature that leaves takes its purse with it, including gold it picked up off the floor (gold-on-the-floor.md section 12.4). creature-leaving.md already described it as discarding carried gold.
