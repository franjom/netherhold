Three arguments: creature, target position, option word; returns whether a route was found. Option bits 1, 2 and 7 go to creature +0x3E6 bits 17, 18 and 19 (cleared first). It sets 0x006EC9D0 (owner's +0x10FC), 0x006EC9D4/D8/E0 (those three bits), 0x006EC9DC (definition +0x686 bit 5) and 0x006EC9E4 (definition +0x686 bit 4). It then writes the entity position into the body with zero velocity through 0x004D59A0, builds the flags byte (option bit 3 -> flag bit 0, bit 4 -> bit 1, bit 5 or bit 6 -> bits 2 and 3 together; option bit 0 unread) and calls 0x004D59E0, which shifts the target up four and calls 0x004D5100, storing the byte at body +0x10D. So 0xE8 -> 0xD and 0xE0 -> 0xC; flag bit 2 turns on the integrator's arrival snap. No same-tile shortcut here. In seed01 every claim walk's body reads flags 0xC.
