Read whole. It adjusts the size by width:
- 512: -2;
- 400: -2 below 11, otherwise -4;
- 800: +2;
- 1024: +4;
- any other width, 640 included: unchanged.

It then switches on the size, through a byte table at 0x553764 into a jump table at 0x553738:
- 6 → 0x444 (FONT_INGAME7);
- 8 → 0x445;
- 10 → 0x447;
- 14 → 0x449;
- 16 → 0x44A;
- 18 → 0x44B;
- 20 → 0x44C;
- 22 → 0x44D;
- 24 → 0x44E;
- any other size → 0x448 (FONT_INGAME12).

The file names come from residx.dat.

The width argument comes from 0x00402D00, which passes +0x10CA. 0x0052B8F0 fills that field from DAT_00756EEC. That DAT_00756EEC is the screen width in pixels is INFERRED: 0x0052B8F0 also stores 0x280 and 0x1E0, and 0x00402D00 sizes the subtitle buffer by it. No mode-setting writer was read.
