It indexes the handler table at 0x004E4B23, loads slot +0x15 and calls it thiscall on the room; a zero return ends the routine, while a non-zero return or a null slot continues into a tick stamp at room+0x73 and further work that is not described. For a portal the slot is 0x004DBBE0, the arrival-interval routine; for the Combat Pit it is 0x004D7A60 (combat-pit.md §8). The slot map and this caller are CONFIRMED in portals-room-handler-table.md, and DECISIONS.md (ADR-0086 amendments) records it as the last of the twelve indexing sites to be placed. Not mirrored as one dispatcher in src/; the per-type handlers are built in their own systems.
