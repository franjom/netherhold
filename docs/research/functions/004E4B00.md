Read 2026-10-01 by disassembly. ECX is the room. For a type byte `+0x18` in 1..0x1A it takes the handler record at `0x006A1E9F + type × 0x29` (the LEA at `0x004E4B23`, which an earlier reading took for the table's address); other types have none. It loads the slot at entry `+0x15` and calls it thiscall on the room; a zero return ends the routine, while a non-zero return or a null slot continues into a tick stamp at room+0x73 and further work that is not described. For a portal the slot is 0x004DBBE0, the arrival-interval routine; for the Combat Pit it is 0x004D7A60 (combat-pit.md §8). The slot map and this caller are CONFIRMED in portals-room-handler-table.md, and DECISIONS.md (ADR-0086 amendments) records it.
