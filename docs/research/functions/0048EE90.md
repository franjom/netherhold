`__thiscall` on the creature with the tile coordinates (x, y). It reads the tile's owner. If `+0x4A3` is already non-zero, or the tile is the creature's own or the neutral player's `[0x006F2548]`, it zeroes `+0x4A3` and returns. Otherwise it walks every player from the list head at `owner+0x10FD` and each player's creatures, and for each whose effective owner (`+0x455` when `+0x453` is set, else `+0x28`) is allied with the tile's owner (`Player_IsAllied`) it computes the squared distance to this creature. If this creature's Creeping bit (`+0x3E6` bit 12) is set, that is multiplied by its level-scaled `def+0x760` percent (50 for all but the Horned Reaper, 0 for it). If the result is inside the watcher's `def+0x77B` sight radius squared and 0x004512F0 finds line of sight, the creature is seen: `+0x4A3` is zeroed. If nobody sees it, `+0x4A3` becomes the tile owner's id.

Two callers: the command handler at 0x00517270, which applies it to the sending player's possessed creature (`player+0x134`) at the packet's x, y, and `Hand_PickUp` (0x004BC61D) on a creature of another owner. Whole body read; LIKELY because what sends the command was not traced. Note that Creeping shortens the distance a watcher needs, so it makes the disguise harder to put on, the opposite of a stealth reading; the same term makes a creeping creature a nearer target in combat-target-selection.md §2.
