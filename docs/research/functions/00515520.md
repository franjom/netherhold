Identified by the reviewer of ADR-0338 from its list walks and the byte test at 0x00515843. It also shows player +0xC is the trap list and +0xE the doors.

Self as a friendly candidate (2026-10-12): friendly spells (the friendly argument set) keep players that
Player_IsEnemy calls not hostile, the caster's own included, and the creature walk has no
id test, so the caster is a candidate: distance 0, not dying, sight from itself. Score =
4096 - dot(normalised(caster - pose), aim). Aim = (sin yaw, -cos yaw, -cos pitch) x 4096
>> 16, normalised: the horizontal part has length ~4096 whatever the pitch, so the
normalised vertical component is at most ~2896. When the pose X/Y equal the caster's, the
direction is (0, 0, dz) normalised to (0, 0, +-4096) or zero (dz = 0, score 4096), so the
score is at least ~1200, never below the threshold (45 x 2048 / 360 = 256). The caster can
win only if the pose is horizontally off its own position and it is in the cone and nearest
the aim; whether that happens depends on the packet's X/Y source (UNREAD).
