Arguments (t, e, x, y, p). Allocates N from the free list head 0x006A11D4 (else the high-water mark 0x006ECA2C), bumps the live count, writes +0xC = 0 and copies t's sixteen bytes over it. Then t.v[next(e)] = p, N.v[e] = p; t.n[next(e)] = N with the edge bit next(e) set and its constraint bit cleared; N.n[prev(e)] = t with the edge bit prev(e) set and its constraint bit cleared; N's neighbour across next(e) (copied from t) has its word that pointed at t pointed at N. Region id and width classes (0x004C8F50) follow. The caller 0x004CAA50 calls it for the triangle on each side of the edge and links the halves across: t.n[e] = the other side's copy, the other side's n[back] = t's copy. Built as `NavMesh.SplitEdgeHalf` and `SplitEdge` (ADR-0486); ours had kept the opposite half in each triangle.
