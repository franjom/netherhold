address: 0x004CA820
name: NavMesh_CloneTriangle
role: Allocates a triangle slot, reusing the head of the free list when there is one, as a copy of a given triangle with one corner replaced, and links the two across their new shared edge.
confidence: LIKELY
status: READ
evidence: docs/research/navigation-partial-rebuild.md#1-what-the-binary-does

Arguments (source triangle, edge slot, two unused, new point). The slot comes from the free-list head 0x006A11D4 (the list continuing through the slot's +6 link) when the head is not -1, else the high-water mark 0x006ECA2C, which is bumped. The live count 0x006ECA30 rises. The new triangle is a copy of the source with byte +0xC reset. The given point is written into one corner of each triangle, which become neighbours across the new edge. That edge is the slot after the given one on the source and the slot before it on the new triangle; on each, its +0xD edge bit is set and its constraint bit (that slot + 3) cleared. The outer neighbour's back link is pointed at the new slot. The source's region id is cleared, the new triangle's +0xE zeroed, and both get width classes recomputed (0x004C8F50). Returns the new slot. This is what makes slot reuse last in, first out after 0x004CB8C0 and 0x004CB170 free triangles.
