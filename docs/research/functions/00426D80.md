Read in disassembly 0x00426D80..0x00426E38. Finds menu 0x2B through 0x0052C540, walks its widgets (+0x6A head, +0x7C next) for +0x74 == id, takes its rectangle (0x00528570), converts it with 0x0052C630, and writes ((left + right) / 2, (top + bottom) / 2) to the out pointer. Hud_StartBattleFlyIn calls it with id 1, the Battle tab.
