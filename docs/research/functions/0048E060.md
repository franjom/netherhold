The only writer of `Flags` bit 4 besides the constructor's `0x09` (a raw `.text`/`cseg` scan of `+0x46F` stores). Exactly four callers, each passing bit 4 of an authored `Flags` byte: trigger action type 1 (`0x00518C3F`) and the neutral, Good and keeper placed-creature loaders (`0x005203C2`, `0x005207D7`, `0x00520B1E`). No shipped placed creature or type-1 action sets the bit, so in the shipped game it is clear on every creature: a Good creature never withdraws and the withdraw state never picks a hero gate. Siblings for the other bits: `0x0048DF10` (0), `0x0048DF40` (1), `0x0048DF70` (2), `0x0048DFA0` (3), `0x0048DFD0` (5), `0x0048E000` (6), `0x0048E030` (7).
