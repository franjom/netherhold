Called by CMap_Load (0x0044E9E0) after Steering_Init. Row-major over the map: tile +0xA = 1, Tile_SetOwner(0), +2 &= 0xF000, +6 = 0, +4/+5 = 0, +0xB |= 0x20, NavCache_SetTileSilent(x, y, 8). So a not-yet-loaded tile reads as Impenetrable Rock, solid, Torch-flagged; terrain 0 never reaches the terrain table (whose entry 0 is null) during a load. Primary source: DKII.EXE decompilation.
