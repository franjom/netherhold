Read whole. Two of the three modes are read through their callers: Presentation_Update's hover tint sets mode 0 (+0x4C bit 0x80), which returns 0x200, the overlay pass the mesh draws skip on additive and alpha-blended materials; for a door or trap of type +0xF6 = 8 (Fear Trap, Hero Portcullis) it sets mode 1 (+0x4D bit 0), which returns 0x600, whose 0x400 lets the overlay cover those materials too. The 0x100 mode (+0x4D bit 1) is not traced to a caller.
