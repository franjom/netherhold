Uses unsigned item bytes+0x0C/+0x0D, swapping reversed endpoints. Item+0x18 bit1 interpolates using instance byte+0x45; otherwise item+0x1C bit1 uses+0x46, scaled /100. Random branch is min+rotr(next sound LCG,13)%(max-min), no draw for equal endpoints. Missing item returns100. No clamp in this helper.
