Thiscall on the bridge with (x, y, terrain, list). When the tile is unexplored and not revealed (tile +9 bit 0x20, slot +0xDC, 0x0044DB70 all false) it substitutes terrain 0x1B, or 0x26 when tile +0xB bit 0x40 is set and the terrain lacks +0x17B bit 0x1000000. A terrain without +0x17B bit 0x10 goes to 0x0043E860 (unread); a room terrain goes to 0x00443610 only when the tile is visible. Called from 0x0043C310.
