It returns 1 while busy; afterwards, when the byte `+0xAB` (state 93's `HungerNeed != 0`) is set it calls `SetState(92)`, otherwise it returns 0 and the dispatcher idles the creature (travel-states.md §8, CONFIRMED). This loop is what makes `HungerFill` mean chickens needed to be full (eating.md §7). eating.md's own text is slightly inconsistent: §2.2 gives 94 this after-meal role and 95 the eating animation, while §7 says the original "goes to 0x5E (wait out the animation)" and uses 0x5F for a random wander; the travel-states reading agrees with §2.2.
