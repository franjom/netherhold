Walks the player's task list (+0x1105) with 0x00507E40(2)/0x00507E90 and submits a 20-byte action record (tile, tile, 0, 0x29, player tag) to 0x0050E5C0 for each. When that returns 0 it asks world slot +0x6C (0x00509450) for the tile's terrain and sets a failure flag if +0x17B bit 1, Impenetrable, is set; it returns the flag's negation. Action 41's handler 0x005129E0 always returns 1, so the flag cannot be set in 1.70 (see 0x0050E5C0). Ours untags the same tiles once per tick and takes success.
