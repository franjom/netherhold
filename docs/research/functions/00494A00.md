It reads `def + id × 27 + 0xB` bit 0; ids 0x25-0x29 are written out separately but land on the same stride (0x3F2, 0x40D, 0x428, 0x443, 0x45E), so it is one table. 0x00494860 returns the same record's address, and the constructor passes such a record to 0x004B37D0, which installs it as the thing's render resource (type byte `+0xA`, flags `+0xB`, frame counts at `+4`/`+8`). The records are therefore compacted art resources, and bit 0 is read as "this creature has that art". Callers: state 116, the job routine 0x0048BE50 and three sites in 0x004567D0.

In state 116 (0x00473350), once no action is running, it rolls random(100). Without record 9 a roll below 20 returns the prisoner to 115. With it, rolls 0-9 instead start action 0x29 (41) with variant 2-4 (an idle flourish) and only 10-19 return to 115, so its step rate is 10 in 100. Record 9 is the Angry animation: 0x00492320 fills record i from the file's ArtResource i (offset 0x20 + 84i) through 0x00504D80, which stores the resource's flags dword at +0xB and its type at +0xA, and only when the resource loads.
